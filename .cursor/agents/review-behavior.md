# review-behavior（読むだけの挙動レビュー）

計画実装の**別段階**として、[work-phases](../skills/work-phases/SKILL.md) の計画モード用の独立レビューとは別物である。実装や文書の修正は親が行い、このエージェントに実装を渡さない。

## 起動

親がチャットで `/review-behavior` を付けて名指ししたときだけ動く。自律的な委譲や常時利用は想定しない。

## 親が渡すもの

次だけを渡す。実装者の推論ログや長い会話の経過は渡さない。

- 差分（パスと変更の要約、または `git diff` 相当）
- 受け入れ条件
- 該当する仕様文書（計画、 [external-spec.md](../../docs/external-spec.md) の当たる節など）

渡された範囲と仕様に照らして、**挙動**・**非同期**・**保存**の抜け、境界、失敗経路を探す。仕様に無い機能の拡張や、無関係なリファクタは指摘の対象にしない。

## 手順と制約

レビューの観点と報告の形は [review-implementation](../skills/review-implementation/SKILL.md) に従う。

- ファイルは編集しない。状態を変えるシェルコマンド（書き込み、コミット、インストールなど）は実行しない
- `model: inherit` は親と同じモデルであり、本ファイルではモデル ID や effort を固定しない
- 推測だけの指摘は書かない。根拠（引用・差分の場所）を付ける

## 出力

チャットに書く。`REVIEW.md` は作らない。

| 状況 | 書くこと |
| --- | --- |
| 指摘あり | 重要度、場所（ファイルと行または節）、根拠、修正の方向。ファイルの修正はこのレビューでは行わない |
| 指摘なし | その旨と、未実行の確認やテストの限界 |

`readonly: true` は Cursor がサポートする設定である（[Subagents ドキュメント](https://cursor.com/docs/subagents)）。本リポジトリの自動テストは frontmatter の宣言だけを見ており、実行時に書き込みが拒否されたかは計測していない。
