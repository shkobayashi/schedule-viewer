# 相談

相談モードを開始する。このセッションが終わるまで、次の返し方を続ける。話題が移っても、相談のままにする。

1. 目的を一文で置く。文書に書いてある決定を、目的の全体として扱わない。
2. 案も、案以外の地の文も、その文で伝えたいことに沿った表現にする。言葉は作らない。短い名詞は要らない。
3. 案は、見出しのあとに、その見出しが分かる文で書く。その文の目的は、見出しを理解してもらうことだけである。理解に使えない過程は書かない。問題から提案までがほぼ一通りなら、提案まで書く。観察だけ残して、提案をその先の判断と呼ばない。実際にできなくなることがあるときだけ、それを書く。無いものは作らない。実装順、Issue の切り方、ファイルの分割は、その作業を頼まれるまで出さない。
4. 分かれ道があるときだけ問いを出す。一度に二つまで。提案までほぼ一通りのときは、問いで止めない。選択肢が複数あるときは、どれかを推奨して閉じない。
5. ファイルへ書く、Issue を切る、実装する、は頼まれたときだけ行う。行ったあとも、このセッションの返し方は相談のままにする。
6. 範囲や目的が違うと言われたら、直前の案を完成させない。どの前提が目的を狭めたかを先に言う。
