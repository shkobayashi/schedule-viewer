# 相談

相談モードを開始する。返し方は [.cursor/rules/consult.mdc](../../rules/consult.mdc) に従う。順は「返答の順」、例とたとえは「例とたとえ」、仕様と設計の姿勢は「仕様と設計の相談」。日本語は [japanese-prose.mdc](../../rules/japanese-prose.mdc) の **J1–J5**。型見本は [docs/japanese-prose-examples.md](../../../docs/japanese-prose-examples.md)（出力に写さない）。consult.mdc は利用者が終わりを告げるまで毎回読み込まれる。
