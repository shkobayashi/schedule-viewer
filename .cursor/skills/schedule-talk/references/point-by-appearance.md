# 見た目で指す

人が見た目で指すとき、色の名前や値では話さない。文脈から推論し、一つに定まらなければ人に確認する。どう問い合わせると話しやすいかは、範囲と絵が同じ画面を指しているかの確認とは別に扱う。

まず read-screen または MCP の読み取り 3 つ（必要なら `current_schedule`）と、付く PNG を読む。数えるのはタスクの件数ではなく、言葉が指している見た目である。各タスクの `visibility` が `visible` のものだけを数える。畳んだ行とスクロールの外は数に入れない。

## 候補にする見た目

- **ステータスのバーの地** — `statuses` の各項目の色。今効いている配色は `view.colorScheme.effective` が `light` か `dark` かで、`color.light.bg` か `color.dark.bg` を見る。値の意味は Issue #421 で渡す読み取りの `statuses` を使う
- **行の地** — `colors` 一覧の、今効いている light か dark の `bg`。タスクに `colorId` があるときだけ、その id の地を見る
- **期限超過の赤** — 応答に専用フラグは無い。終了日が今日より前で、ステータスの扱いが未着手か着手済みのとき。完了、管理外、一覧に無い `status` の id は超過にしない。終了日が今日なら超過にしない。当たるのは枠と左のタスク名で、バーの地はステータスのままである
- **未割当の琥珀** — 担当が空の左の札と、行の左端の細い色
- **メンバー不明の紫** — 左の担当の札。並びの id がすべてメンバー一覧に無いときだけ
- **未確定の斜線** — 斜線はタスクバーだけ。地はステータス色のまま斜線を重ねる
- **確定のマイルストンの塗りつぶしたひし形** — 人が「ひし形」や「マイルストン」と言うときだけ候補にする
- **未確定のマイルストンの中空のひし形** — 未確定のひし形は中空。輪郭だけ同系色で、中を空ける。人が「斜線」や「中空」と言うときは、タスクの斜線と区別する

マイルストンは帯にある。`current_schedule` の各マイルストンの `confidence` と、`view.visible.dates` にその日が入るか、絞り込みで帯を隠している条件にそのグループが無いかで、見えているかを決める。

一つのタスクに、バーの地、行の地、期限超過、斜線、未割当が同時に付くことがある。

## 言葉と候補

「斜線」は、タスクのバーだけを指す。「中空」は、未確定のマイルストンのひし形を指す。タスクの斜線と未確定のひし形が両方見えていて、言葉が両方に当たるときは人に確認する。

「ひし形」や「マイルストン」まで言うときは、見えている塗りつぶしと中空の両方を候補にする。

イナズマ線は候補にしない。`view.lightning` がオンで、未割当の琥珀と橙の言葉が両方に当たるときは人に確認する。

半透明のあいだは人に確認する。半透明の面がチャートに乗っているあいだは、色で一つに決めない。面の有無は読み取りの項目に無く、PNG で見る。

## 決め方

見えている範囲でその見た目が一つに定まり、言葉がその意味に合うときだけ、それを指す。意味が二つありうるとき、同じ見た目が何件もあるときは、候補の名前を短く示して人に確認する。

色は、タスク、左の札、マイルストンを指す手がかりにとどめる。色は選ぶ材料にしない。ステータスや `colorId` を選ぶ材料にもしない。選ぶ材料は、screen-judgment のとおり説明である。
