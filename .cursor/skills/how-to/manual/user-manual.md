# 操作マニュアル

ブラウザ向けの公開版は https://shkobayashi.github.io/schedule-viewer/ にあります（`main` に入った内容が載ります）。

schedule-viewer の手順は、次の四つに分けてあります。ボタン名や色の意味が文書と違って見えたときは、挙動を定めている [外部仕様](external-spec.md) を確認してください。

| 文書 | 読むとき |
| --- | --- |
| [はじめに](user-manual/getting-started.md) | 起動し、見て、手または LLM で一か所直して保存するまで |
| [やりたいことから探す](user-manual/find-by-intent.md) | 「〜したいとき」から全機能の該当箇所へ飛びたいとき |
| [チュートリアル](user-manual/tutorial.md) | スキルで JSON を作り、MCP で取り込み直す長い流れ |
| [全機能](user-manual/features.md) | ボタン名と操作を網羅して調べたいとき |

はじめにを読んだあと、目的に合わせて [やりたいことから探す](user-manual/find-by-intent.md) または [チュートリアル](user-manual/tutorial.md) へ進みます。画面の細かい操作は [全機能](user-manual/features.md) を見ます。
