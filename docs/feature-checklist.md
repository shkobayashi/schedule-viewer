# 機能チェックリスト

仕様を足すときに、今ある機能のどこへ影響するかを見る一覧である。挙動の条件は [外部仕様](external-spec.md) に書く。ここには、触れるかどうかを判断する行だけを置く。

## 使い方

仕様を書き始める前に、この一覧を上から見る。各行に、触れるか、触れないかだけを付ける。機能の行のあと、機能 ID が付いていないものも見る。

付けた印は、このファイルには書かない。計画には、触れる行の名前を残す。

触れる行は、右の機能 ID を外部仕様で開く。そこで、新しい仕様を書く。触れない行の条件は繰り返さない。

触れる行が複数あるときは、そのうち一つだけを変えたときに、ほかの行が今までどおり動くかを書く。迷った行は、触れる側にする。

機能 ID を増やすとき、行の境を変えるとき、利用者の操作の入口を増やすときは、この一覧を同じ変更で直す。外部仕様の文面だけを直すときは、直さない。

今ある機能 ID は、それぞれ下の一覧の一行だけに入る。

## 一覧

各行の機能 ID は、[外部仕様の機能](external-spec.md#機能) の見出しである。まとまりごとに、触れるかを見る。

### ファイルとウィンドウ

スケジュールのファイルを開き、保存し、別のウィンドウと分け合う。

| 見るところ | 触れるときに見ること | 機能 ID |
| --- | --- | --- |
| 開く経路 | メニューから開く、ドロップ、最近使ったファイル、アイコンやショートカット、前回のファイルのどれが、新しい状態を残し、どれが捨てるか | `FILE-01`、`FILE-08`、`FILE-09`、`WIN-04`、`SYNC-03` |
| 設定ファイル | 設定ファイルを開いているウィンドウと、アプリの設定で、メンバー、ステータス、カレンダー、色の一覧、拡張項目のどれを読むか。新しいフォルダへ書き出すときに、どれを含めるか | `FILE-10`、`FILE-11` |
| 保存と未保存 | 文書が変わるなら、未保存の印、保存、別名保存、閉じるときの確認、JSON の表示、差分の表示のどれに乗るか | `FILE-02`、`FILE-03`、`FILE-04`、`FILE-05`、`FILE-06`、`FILE-07` |
| 外からの書き換え | 編集の途中やダイアログを開いているあいだ、ディスク側の更新を止めるか、知らせるか。保存の直前にディスクが変わっていたときを含む | `SYNC-01`、`SYNC-02` |
| 別ウィンドウ | 同じスケジュール、メンバー、カレンダー、表示の設定を、もう一つのウィンドウが持つか。持っているなら、変更を知らせるか | `WIN-01`、`WIN-02` |

| バーの移動と期間 | チャート上のドラッグで日付を変える。移動と期間変更のどちらが変わるか | `EDIT-02`、`EDIT-03` |

| 名前、ノート、階層の定義 | タスクのノート、カテゴリとグループの名前、スケジュールのタイトル、段の名前と意味と指示のどれを直すか | `EDIT-06`、`EDIT-13`、`EDIT-20`、`EDIT-21` |

## 機能 ID が付いていないもの

機能 ID は付いていない。該当したら、示した節を開く。

| 見るところ | 触れるときに見ること |
| --- | --- |
| アプリが持たないもの | 稼働日を踏まえた期間の計算、前後関係に合わせた日付の自動変更、アプリから LLM への接続を、新しい仕様がアプリ側に持たせていないか。[スコープ](external-spec.md#スコープ) を見る |
| ダイアログ | 新しいダイアログは、Escape で閉じ、フォーカスを中に留め、背面を操作できないようにするか。開いているあいだ、外のファイルをすぐ反映するか。出る条件が変わるダイアログは、[ダイアログ](external-spec.md#ダイアログ) の表に行があるか |
| 上限 | 件数、バイト数、取り消しの段数、候補の件数、書き出しの大きさが、[上限値](external-spec.md#上限値) の内側か。外側なら、その節へ足す |
| JSON の形 | フィールドや schemaVersion を変えるなら、スケジュール、メンバー、カレンダー、色の一覧、拡張項目、設定ファイルのどれか。[データ仕様](data-format.md) を開く |
| ブラウザ版とデスクトップ版 | 開く、保存、監視、控え、別ウィンドウ、自動更新の差が増えるか。[動作環境](external-spec.md#動作環境) の表に、その行があるか |
| 空と不明 | 0件、未選択、割り当てなし、一覧に無い id、開くファイルが無いとき、何も変えないのか、知らせるのか |
