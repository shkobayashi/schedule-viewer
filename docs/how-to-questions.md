# how-to スキル検証用の質問

このファイルは、Issue #344 の 8 問を記録する。スキル同梱物には含めない。見出し検査は、ここに書いた `ファイル名#見出しid` だけを対象にする（将来 LLM が返す引用は対象外）。

## 1. タスクの期間をチャート上で動かすやり方を教えて

- 手順:
  チャート上のタスクのバーの本体（左右の端ではないところ）を横にドラッグします。少し動かすだけでは選択だけが変わり、8px を超えると移動が始まります。ドラッグ中は開始日と終了日が出て、マウスを離すと確定します。やめるときは離す前に Escape です。2件以上選んでいるときは、選んだバーをドラッグすると、選択中のタスクが同じ日数だけ動きます。
- 添えた箇所: `features.md#選択と移動`
- 見出し検査: 合格
- 手順が、添えた見出しの中の操作で一通りになっているか: 合格
- 添えた見出しだけを読んで、手順を組み直せるか: 合格
- アプリでその手順を実行して片付いたか: 合格

## 2. 絞り込みで残した行だけを HTML に書き出すやり方を教えて

- 手順: 
画面上部の検索欄と「絞り込み」パネルで、残したい行だけになるように条件を掛けます。その状態で ☰ の「書き出し」を開き、形式に HTML を選んで「書き出す」を押し、保存先を決めます。絞り込みで隠したタスクは書き出しに入りません。画面の外にスクロールしている行は入ります。
- 添えた箇所: features.md#絞り込む、features.md#書き出す 
- 見出し検査: 合格
- 手順が、添えた見出しの中の操作で一通りになっているか: 合格
- 添えた見出しだけを読んで、手順を組み直せるか: 合格
- アプリでその手順を実行して片付いたか: 合格

## 3. タスクを複製して、複製先の日付だけ変えるやり方を教えて

- 手順: 
複製したいタスクを1件選び、右クリックの「複製」、または選択中に Alt+Shift+↓ でダイアログを開きます。写った内容のうち日付だけを直し、「追加」を押します。同じグループの直後に足されます。キャンセルや Escape では増えません。
- 添えた箇所: features.md#右クリックと複製
- 見出し検査: 合格
- 手順が、添えた見出しの中の操作で一通りになっているか: 合格
- 添えた見出しだけを読んで、手順を組み直せるか: 合格
- アプリでその手順を実行して片付いたか: 合格

## 4. 休日をチャートに塗るやり方を教えて

- 手順:
☰ の「設定」を開き、「稼働日」で休日と振替出勤を書いた JSON を1件取り込みます。未設定のときは土日が塗られます。月表示では塗りません。
- 添えた箇所:
features.md#設定、features.md#色と線の見かた
- 見出し検査: 見出しはあるが、設定からだと目的の箇所を探すのが大変
- 手順が、添えた見出しの中の操作で一通りになっているか: 未実施
- 添えた見出しだけを読んで、手順を組み直せるか: そのJSONをどう作るの？と疑問になりそう
- アプリでその手順を実行して片付いたか: 不合格

## 5. 担当が「メンバー不明」になるときの直し方を教えて

- 手順:
設定の「メンバー」で、その担当 ID を含むカタログを選びます。カタログを選んでいないときも、ID がある担当はメンバー不明になります。
- 添えた箇所:　features.md#担当がメンバー不明になる、features.md#設定

## 6. 未保存の画面をファイルへ保存するやり方を教えて

- 手順:
☰ の「保存」、または ⌘S（Windows と Linux では Ctrl+S）で、今の画面をファイルへ書き込みます。開いているファイルがあるときは上書きです。まだ保存先が無いときは、保存先を聞きます。
- 添えた箇所: features.md#ファイルを開く保存する

## 7. キーボードで選択を隣のタスクへ移し、そのタスクを削除するやり方を教えて

- 手順:
↑↓ で、見えている隣のタスクへ選択を移します。その状態で Delete または Backspace を押し、出た確認のあとで削除します。
- 添えた箇所:features.md#選択と移動、features.md#追加と削除

## 8. 別のプログラムがファイルを書き換えたあと、画面の変更とファイルの変更の両方を残すやり方を教えて

- 手順:
未保存の編集があるときに「ファイルが更新されています」が開いたら、「画面」と「ファイル」の節を読んだうえで「両方を画面へ反映」を選びます。画面とファイルが別の箇所だけを変えていて衝突が無いときだけ選べます。まとめた内容は画面の未保存に置かれるので、そのあと保存してファイルへ書きます。
- 添えた箇所: features.md#ほかのプログラムがファイルを書き換えたとき
