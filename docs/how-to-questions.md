で残した行だけを HTML にするには、先に条件を掛けて画面に残したいタスクだけが見える状態にしてから、☰ の「書き出し」で HTML を選んで保存します。

<details><summary>answerer 回答（全文）</summary>

状態バーに「未保存」と出ていることを確かめます。内容をファイルに残す前に、☰ の「差分を表示」や状態バーの「未保存」で、開いているファイルとの違いを見ておくと安心です。

ファイルへ書き込むときは、☰ の「保存」を選ぶか、Mac では ⌘S、Windows と Linux では Ctrl+S を押します。macOS のデスクトップ版では画面上部のファイルメニューからも同じ保存が選べます。⌘ または Ctrl+K のコマンドパレットで「保存」と打って実行しても構いません。

すでに開いているスケジュール JSON があるとき、「保存」はそのファイルへ上書きします。まだ保存先が無いとき（サンプルのみなど）は、初回だけ保存先を聞かれるので、書き込みたい場所とファイル名を選びます。別のパスに新しく残したいときは、☰ の「別名保存」か ⌘ または Ctrl+Shift+S を使います。別名保存は、いつも保存先を聞きます。

保存に成功すると、状態バーの「未保存」が消え、開いているファイル名が状態バーやウィンドウのタイトルに出ます。必須の追加項目が空のタスクがあると、スケジュールの保存はできません。保存の途中に、ほかのプログラムが同じファイルを書き換えていた場合は、「上書き保存」「別名保存」「取り消し」から選びます。

参照: `features.md#ファイルを開く保存する` `features.md#画面の見かた` `features.md#操作早見表` `features.md#ほかのプログラムがファイルを書き換えたとき` `getting-started.md#手で一か所直して保存する`

<details><summary>answerer 回答（全文）</summary>

まず削除したいタスクを、チャートのバーか左の名前をクリックして選びます。まだ何も選んでいないときは、ここから始めてください。

次に、↑ または ↓ を押して、見えているタスクのひとつ上か下へ選択を移します。カテゴリ行とグループ行は飛ばされます。移した先のタスクが画面外のときは、一覧が自動で動いてその行が見えるようになります。

移した先のタスクが選ばれた状態で、Delete または Backspace を押します（Mac では Backspace キー）。同じ確認は、ツールバーの「削除」からも開けます。右クリックメニューの「削除」でも同じです。表示された確認で削除を確定すると、そのタスクが消えます。消しすぎたときは、⌘+Z（Windows では Ctrl+Z）で取り消せます。

↑↓ で選択が動かないときは、検索欄やダイアログに文字を入れている、詳細パネルの入力欄にフォーカスがある、絞り込みパネルを開いている、などの可能性があります。チャート側をクリックしてから、もう一度 ↑↓ を試してください。線の上で Delete を押すとタスクではなく線だけが外れるので、バーかタスク行を選んだ状態で削除してください。

`features.md#選択と移動` `features.md#追加と削除` `features.md#操作早見表` `features.md#取り消しと入力中のキー` `features.md#モード中のキー`

うまくいかないときは、上に挙げた箇所をマニュアルで読んでみてください。

</details>

<details><summary>answerer 回答（全文）</summary>

別のプログラムが開いているスケジュールを書き換えると、デスクトップ版では未保存の画面編集があるとき「ファイルが更新されています」が開きます（あとから戻るときは状態バーの「ファイルに更新あり — 確認する」）。まず「画面」と「ファイル」の節で、それぞれどこが変わったかを読みます。

画面とファイルが別の箇所だけを変えていて、同じ項目がぶついていないときは、「両方を画面へ反映」を選びます。起点からまとめた内容が画面の未保存になり、ディスク上のファイルはまだ古いままです。チャートや差分で内容を確認し、問題なければ ☰ の「保存」でファイルへ書き込みます。これで画面で足した変更と、別プログラムが入れた変更の両方がファイルに残ります。

同じ箇所がぶついているときは、この確認画面だけでは一つにまとめられません。「依頼文をコピー」で文をチャットに貼り、MCP または read-screen で `baseline_diffs` を読ませ、衝突していない部分は組み直し、ぶつかった部分はどちらを採るか答えたあと、`write-schedule` の形でスケジュール全体を組み立てて `replace_schedule` で画面の未保存だけ置き換えます（ファイルには自動では書きません）。画面に反映された内容を確認し、問題なければ保存してください。衝突があるこの確認が開いているときだけ `replace_schedule` が使えます。

参照: `features.md#ほかのプログラムがファイルを書き換えたとき`、`features.md#ファイルを開く保存する`。うまくいかないときは、上記の見出しの本文を読んでください。

</details>
