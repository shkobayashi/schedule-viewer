# 外部仕様

画面と機能の挙動を定める。正本はソースコードで、挙動を変えたらこの文書も直す。利用者向けの手順は [操作マニュアル](user-manual.md)、ファイルの形は [データ仕様](data-format.md) にある。

機能 ID は `FILE-01` の形である。テスト仕様は、この ID で自動テストと手動テストケースを対応づける。

## スコープ

アプリは、検証済みのスケジュール JSON を表示し、絞り込み、編集し、書き出す。次のことはしない。

- 稼働日を踏まえた期間の計算や、前後関係に合わせた日付の自動変更
- LLM への接続。スケジュール、メンバー、カレンダーの生成は、アプリの外のスキルが行う
- タスク、グループ、カテゴリの並び替え。並びは JSON の配列順のままである

## 用語

| 用語 | 意味 |
| --- | --- |
| カテゴリ | スケジュールの最上位のまとまり。識別子は `id` で、名前は表示である |
| グループ | カテゴリの中のまとまり。識別子は `id` で、名前は同じカテゴリの中で重複できない |
| タスク | 開始日と終了日を持つ作業。終了日はその日を含む |
| マイルストン | 名前、日付、確度を持つ時点。タスクではない |
| 対応マイルストン | タスクの `milestoneId` が指すマイルストン。タスクごとに0件か1件で、編集ダイアログの「対応マイルストン」で選ぶ |
| 先行・後続 | タスクの `predecessors` が指す相手が先行、自分を指している相手が後続 |
| 破綻 | 後続の開始日が、先行の終了日より前であること。同じ日に始まる場合は破綻にしない |
| 期限超過 | 完了以外で、終了日が今日より前であること。終了日が今日なら超過にしない |
| マイルストン超過 | 対応マイルストンがあり、終了日がその日付より後であること。当日は超過にしない |
| 割り当てなし | `assigneeId` が `null` であること |
| メンバー不明 | `assigneeId` があるが、使用中のカタログにその ID が無いこと。カタログ未選択も含む |
| カタログ | 設定に取り込んだメンバー JSON の1件 |
| 系統 | 選んだタスクから、先行をそれ以上さかのぼれないところまで、後続をそれ以上たどれないところまでつないだ範囲。起点を通らない枝は含めない |
| 非稼働日 | カレンダーの規則、または未設定時の土日。表示だけに使い、日付の計算には使わない |
| 控え | 未保存の内容を、開いている JSON ファイルとは別にアプリデータへ残したもの |
| サンプルデータ | ファイルを開いていないときの起動用スケジュール |
| 見出し | 画面左上のタイトルと、その右に並ぶ状態の表示をまとめたもの |

## 動作環境

配布物は Ubuntu 22.04 以降の deb と、Windows の NSIS インストーラである。macOS は、使う Mac の上でビルドしたアプリを使う。ビルドの手順は [開発ガイド](development.md#配布用ビルド) にある。

Tauri で作ったデスクトップアプリをデスクトップ版、`npm run dev` でブラウザに開いたものをブラウザ版と呼ぶ。違いは次のとおりである。

| 操作 | デスクトップ版 | ブラウザ版 |
| --- | --- | --- |
| 開く | OS のファイルダイアログ | ファイル選択 |
| 保存、別名保存、書き出し | OS の保存ダイアログ | ダウンロード |
| 外部の更新の監視 | 開いているファイルを約1.5秒ごとに見る | しない |
| 復旧用の控え | 未保存のときアプリデータに書く | しない |
| 前回開いたファイル | パスを覚え、次回そのファイルを開く | しない |
| ウィンドウを閉じる | 未保存なら控えを書くか、サンプルなら確認する。パスが無い状態で閉じると、覚えたパスも消える | ブラウザ標準の離脱確認 |
| メンバーとカレンダー | アプリデータ | localStorage |
| 表示サイズ、配色、左一覧の幅 | localStorage | localStorage |
| 読み書きの上限 | スケジュールと書き出しは 10MB、メンバーとカレンダーは 2MB | フロントには同じ上限を掛けない |

## 画面構成

```
+--------------------------------------------------------------------------------------------+
| ☰  タイトル [状態]  検索  絞り込み  系統  線を引く  追加  マイルストン追加  削除  −  週表示  ＋  Fit |
| Ctrl(⌘)+ホイールでズーム ・ Shift+ホイールで横スクロール ・ ...                            |
+--------------------------+-----------------------------------------------------------------+
| WBS / タスク             | 日付ヘッダー                                                    |
| マイルストン             | マイルストン帯                                                  |
| カテゴリ / グループ /    | 親バー、タスクバー、前後の線、イナズマ線                        |
| タスク                   |                                                                 |
+--------------------------+-----------------------------------------------------------------+
```

左の行と右のチャートは、縦に一緒にスクロールする。左一覧とチャートの境界を横にドラッグすると、一覧の幅を変えられる。左の幅に収まらない名前は、その名前を横にドラッグして続きを読む。担当と「超過」は動かない。

☰ メニューの項目は「開く」「保存」「別名保存」「書き出し」「JSON を表示」「差分を表示」「設定」である。「開く」「保存」「別名保存」の右には、Mac では ⌘、それ以外では Ctrl のショートカットを出す。ファイル操作の途中は、開く、保存、別名保存、差分を表示を押せない。メニューは外側のクリックか Escape で閉じる。

ダイアログが開いているあいだ、開く、保存、別名保存、タスク名の検索への移動、Enter での編集、Delete と Backspace での削除、線を引く、⌘/Ctrl+矢印でのスクロールは効かない。検索欄、入力欄、選択欄、ボタンにフォーカスがあるとき、開く、保存、別名保存、タスク名の検索への移動、⌘/Ctrl+矢印でのスクロールは効く。線を引く ⌘/Ctrl+L は、検索欄、入力欄、選択欄では効かず、ボタンでは効く。Enter と Delete と Backspace、修飾キーの無い矢印と L は、そのフォーカス先の操作のままにする。

左上のタイトルと、その右に並ぶ状態の表示をまとめて「見出し」と呼ぶ。見出しの状態の表示は、次の表を上から順に見て、最初に当てはまる1つだけを出す。

| 表示 | 条件 |
| --- | --- |
| ファイルを反映しました | 外部の内容を画面へ反映した直後。約4秒で消える |
| 未保存 | 画面の内容が、最後に開いた・保存した・読み直した内容と違う |
| ファイル名 | 保存済みで、開いているパスまたはブラウザで選んだ名前がある |
| 保存済み | 保存済みだが、表示する名前が無い |
| サンプルデータ | 上記のどれでもない。起動直後もここに入る |

見出しには、条件を満たすときだけ次も並ぶ。

- 「ファイルに更新あり — 読み直す」。外部の更新を保留しているとき。押すと読み直す確認に戻る
- 使用中のメンバーカタログ名
- 「メンバー設定エラー」。設定の読み込みに失敗したとき。詳細はツールチップ
- 「カレンダー設定エラー」。カレンダーの読み込みに失敗したとき。詳細はツールチップ

画面上部のヒントは、ズーム、横スクロール、ドラッグでのスクロール、名前の横ずらし、⌘/Ctrl+ドラッグでの移動、端のドラッグ、操作中の開始日と終了日、ダブルクリックでの編集を示す。

### FILE-01 開く

**操作** ☰ の「開く」。⌘/Ctrl+O でも同じ。

**挙動** 選んだ JSON を検証し、通れば画面のスケジュールを置き換える。見出しはファイル名になる。絞り込み、折りたたみ、系統、選択、取り消し履歴は初期状態に戻し、期間が幅に収まるよう Fit する。検証に失敗したファイルは開かず、それまでの保存先も変えない。エラーは日本語で、場所はカテゴリ、グループ、タスクの名前で示す。

**制約** 未保存のときは、破棄して開くかキャンセルするかを先に選ぶ。デスクトップ版の読み込み上限は 10MB。開けるのは schemaVersion 3、4、5 である。3 は、確度が無いタスクを確定として読む。4 は、カテゴリとグループに名前から決まる `id` を付ける。どちらも schemaVersion 5 にする。開いた直後の未保存の比較元は、その移行後の保存形式である。ディスク上の文字列とそのまま比べないので、開いただけでは未保存にならない。同じ 3 または 4 を開き直しても、付けた `id` は変わらない。保存すると schemaVersion 5 で、全部のタスクとマイルストンに `confidence` が入り、カテゴリとグループに `id` が入る。マイルストンに確度が無い 3、4、5 は、そのマイルストンを確定として読む。schemaVersion 2 は開けない。

### FILE-02 保存

**操作** ☰ の「保存」。⌘/Ctrl+S でも同じ。

**挙動** 開いているパスがあれば、そのファイルへ今の内容を書く。無ければ別名保存と同じく保存先を選ぶ。成功すると未保存が外れ、控えは消える。

**制約** デスクトップ版は、開いているパスと保存先が一致するときだけ上書きする。書き込み上限は 10MB。ディスクの内容が開いたときと違えば SYNC-02 に進む。ブラウザ版は常にダウンロードで、パスは残らない。

### FILE-03 別名保存

**操作** ☰ の「別名保存」。⌘/Ctrl+Shift+S でも同じ。

**挙動** 保存先を選び、今の内容を書く。成功すると、そのパスが次の上書き先になる。

**制約** 拡張子は `.json`。ブラウザ版はダウンロードし、表示上のファイル名を外すので、見出しは「サンプルデータ」に戻ることがある。中身の未保存は、ダウンロードした内容と一致すれば外れる。

### FILE-04 未保存の判定

**操作** 見出しの状態を見る。

**挙動** 保存形式にした画面の JSON と、最後に開いた・保存した・読み直した JSON が違えば「未保存」になる。インデントやキー順だけの違いは、同じ内容として扱う。

**制約** 絞り込み、折りたたみ、ズーム、スクロール、系統、選択は未保存にしない。ダイアログで確定する前の入力も、未保存の判定には含めない。

### FILE-05 閉じるとき

**操作** ウィンドウまたはタブを閉じる。

**挙動** デスクトップ版で、開いているファイルがあり未保存なら、控えを書いてから閉じる。保存済みで閉じても、開いていたパスは残る。サンプルのまま未保存なら、破棄して閉じるかキャンセルするかを選ぶ。破棄して閉じると控えも消える。パスが無い状態で閉じると、覚えていたパスも消える。ブラウザ版は、未保存のときブラウザ標準の確認になる。

**制約** 次回に戻るのはスケジュールの内容と開いていたファイルだけである。絞り込みやスクロールは戻らない。

### FILE-06 JSON を表示

**操作** ☰ の「JSON を表示」。

**挙動** 今のスケジュールを、保存と同じ形式の JSON で見せる。ファイルには書かない。

**制約** 編集はできない。

### FILE-07 差分を表示

**操作** ☰ の「差分を表示」。

**挙動** 今の画面を保存と同じ形式にしたものと、開いているファイルをダイアログを開いた瞬間に読んだ内容との差を、選択できるテキストで見せる。「コピー」でその全文を写す。ファイルには書かない。表示は開いた時点のままで、開き直すとファイルを読み直す。パスが無いとき（サンプル、ブラウザ版）は「比べるファイルがありません」と出す。差が無いときは、見出しのあとに「差はありません」と出す。

タスク、マイルストン、カテゴリ、グループは id で対応づける。同じ id でカテゴリまたはグループの名前だけが違うときは、`変更 カテゴリ` または `変更 グループ` として `name` の前後を書く。同じ id のグループが別のカテゴリにあるときは、削除と追加にせず、`変更 グループ` の場所に移す前と移したあとの「カテゴリ名 / グループ名」を書く。名前も違うときは、場所のあとに `name` の前後を書く。親の id が同じタスクは、親の改名だけでは場所を出さない。場所の表示はカテゴリ名とグループ名のままである。同名でも id が違えば削除と追加である。別のグループへ移したタスクは、場所の変更として出す。変更と追加は画面の並び、削除はファイルの並びで書く。タスクの変わったフィールドだけを、場所、name、start、end、assigneeId、status、progress、confidence、predecessors、milestoneId、note の順で書く。タスクの変更、追加、削除では場所を必ず書く。日付の差は暦日で、`（+7日）` のように書く。先行は集合として比べ、増減だけを書く。追加は場所と全フィールドを書き、兄弟の並びは繰り返さない。削除はファイル側の名前、場所、全フィールドを書く。空のまま残っているグループとカテゴリは削除にしない。タスクを消して先行から外れたことは、残ったタスクの先行の変更として出す。カテゴリ、グループ、タスク、マイルストンの配列は、追加と削除を除いても残りの順が違うときだけ並びとして出す。マイルストンの変わったフィールドだけを、name、date、confidence の順で書く。date の差も暦日である。

**制約** 読めない、10MB を超える、または検証に失敗したときは差分を出さず、開くときと同じ読み込みエラーを出す。絞り込み、折りたたみ、ズーム、スクロール、系統、選択、確定前の入力は含めない。未保存の表示とは別で、画面と今のファイルが同じなら未保存でも差は空である。開く、保存、別名保存の途中は押せない。読んだ内容はこの機能のためには保存しない。スキーマは変えない。

### SYNC-01 外部更新の反映

**操作** デスクトップ版でファイルを開いたままにする。保留中は「ファイルに更新あり — 読み直す」を押す。

**挙動** 約1.5秒ごとにファイルの内容を見る。未保存でなく、編集ダイアログも開いていなければ、検証に通った内容を画面へ即時反映し、約4秒「ファイルを反映しました」と出す。未保存、または編集中なら、「読み直す」か「画面の編集を残す」かを選ぶ。読み直すと画面の編集は捨て、控えも消える。残すと見出しに「ファイルに更新あり — 読み直す」が出て、画面の内容はそのまま残る。検証に失敗した内容は反映せず、同じ内容のエラーを繰り返さない。

**制約** ブラウザ版では動かない。読み取りに5回連続で失敗すると、SYNC-03 の、ファイルが無いときのファイルダイアログを出す。1回だけの失敗では出さない。読み取り失敗の汎用メッセージは出さない。成功すると回数は戻り、同じ欠落では一度だけ出す。自分の保存は外部更新とみなさない。

### SYNC-02 保存時の外部更新の確認

**操作** 外部で変わったファイルに対して「保存」を押す。

**挙動** 「上書き保存」「別名保存」「取り消し」を選ぶ。上書きはそのパスへ書く。別名保存は別のパスを選ぶ。取り消しは何も書かない。

**制約** 開いたあと一度も外部の変化を見ていなくても、保存の直前にディスクと比べる。

### SYNC-03 前回のファイル

**操作** デスクトップ版でファイルを開き、保存して、または未保存のまま閉じて、次に起動する。

**挙動** 開いたファイルのパスをアプリデータに覚える。未保存になってから約1秒後と、閉じる直前に控えを書く。次回、そのファイルがあり、未保存が無いか、ディスクが控えの基準と一致すれば、そのファイルを開く。未保存があれば、その内容を未保存のまま戻す。警告は出さない。ディスクが未保存の内容と違えば、「ファイルを開く」か「未保存の編集を戻す」かを選ぶ。開くならそのパスの最新内容を保存済みとして読み、控えは消す。戻すなら画面は控えのままで、ディスクの内容はあとから読み直せる。

前回のファイルが無く、未保存も無いときは、見つからないことを知らせてサンプルにする。ファイルダイアログは出さない。前回のファイルが無く、未保存があるときは、未保存を画面に戻し、ファイルが無いことを知らせる。「未保存の編集を戻す」はその内容を残す。「ファイルを開く」は、下のファイルダイアログである。この起動でファイルが無いと知らせたあとは、そのファイルが再び読めるまで、監視のファイルダイアログは出さない。

ファイルが無いときの「ファイルを開く」は、起動時の警告と、作業中にファイルが消えたときで同じである。覚えたパスは直接開かず、OS のファイルダイアログを出す。初期フォルダは、保存先の親フォルダが残っていればそこ、無ければホームである。消えたファイルは初期選択にしない。キャンセルすると、画面に出している内容と見出しのパスを残す。未保存なら、破棄して開くかの確認を先に出す。選んだあとは、通常の開くと同じ検証に進む。作業中は、1回読めないだけでは出さず、5回連続で読めなくなってから出す。

**制約** 戻るのはスケジュールの内容と開いていたファイルだけである。絞り込み、折りたたみ、ズーム、スクロール、系統、選択は戻らない。サンプルではパスも控えも作らない。保存、破棄して別ファイルを開く、外部の内容を読み直したときは控えを消す。「画面の編集を残す」では消さない。ブラウザ版ではパスも控えも残さない。上書き保存は、ファイルが無いパスへは書けない。別名保存は書ける。控えが壊れている、またはファイルはあるが検証できないときは、その旨を出してサンプルのままにする。記録は残し、「控えを破棄」で控えを消せる。破棄するまで起動のたびに知らせる。パスが無い状態で閉じると、覚えたパスは消える。

### VIEW-01 階層

**操作** 画面を見る。

**挙動** 行はカテゴリ、グループ、タスクの3段で、JSON の配列順に並ぶ。一致するタスクが無いグループとカテゴリは行に出さない。データとしては残る。

**制約** 並び替えはできない。

### VIEW-02 タスクバー

**操作** タイムラインのタスク行を見る。

**挙動** バーは開始日から終了日の終わりまでを塗る。終了日はその日を含む。未着手は灰、進行中は薄青に進捗率の濃い部分、完了は緑である。選択中は枠を太くする。

**制約** 進捗の塗りは進行中だけに出す。幅は1日より短くならない。

### VIEW-03 親バー

**操作** カテゴリ行とグループ行を見る。

**挙動** 見えている子のうち、最も早い開始日から最も遅い終了日までのバーを、タスクバーの半分の高さで出す。子が途切れている期間は薄い色、つながっている期間は濃い色にする。子の期間が隙間なく続くところは1本につなぐ。折りたたんでも親バーは残る。

**制約** 親バーはドラッグできない。

### VIEW-04 マイルストン帯

**操作** 日付ヘッダーの下を見る。

**挙動** マイルストンをひし形と名前で置く。確定のひし形は塗りつぶす。未確定のひし形は、同じ色の地に斜線を重ねる。名前が重なるときは段を増やす。段は横スクロールでは変わらない。チャート全体へ縦線は引かない。マイルストンが無ければ帯の高さは 0 である。

**制約** 左には、帯があるときだけ「マイルストン」と書いた行を出す。

### VIEW-05 期限超過

**操作** 今日より前に終わる未完了タスクを見る。

**挙動** バーを赤くし、左のタスク名も期限超過の見た目にする。終了日が今日のタスクは超過にしない。完了は終了日が過去でも超過にしない。

**制約** 進捗率では判定しない。

### VIEW-06 マイルストン超過

**操作** 対応マイルストンよりあとまで延びたタスクを見る。

**挙動** マイルストンの日付より右を半透明の赤で塗り、行に「超過」を出す。終了日がマイルストン当日なら超過にしない。対応が未設定なら判定しない。

**制約** 期限超過とは別である。両方あり得る。

### VIEW-07 イナズマ線

**操作** チャート上の本日の線を見る。

**挙動** 基準はパソコンの今日の日付で、日付が変わると更新する。行の中央で折れる。期限超過の行では終了日まで左へ、着手済みで開始日が今日より後の行では開始日まで右へ、それ以外は今日の位置に置く。色は橙色である。

**制約** 進捗率は見ない。未着手で開始日が未来でも、今日の位置のままである。

### VIEW-08 前後の線

**操作** 先行と後続が両方見えているタスクを見る。

**挙動** 先行から後続へ矢印を引く。間隔があるときは先行の右端から右へ出て縦に折れ、後続の左端へ入る。終了と開始が近く、右へ出る余地が矢印の頭より狭いときは、先行バーの外側を回ってから、後続の左端の手前で右を向いて入る。頭は後続バーの外に残る。後続の開始が先行の終了より前なら赤く太くする。同じ日に始まる線は赤くしない。フィルタや折りたたみでどちらかが見えなければ線は出さない。線を引くモードの追随する線は、確定した矢印ではない。バーの移動または端のドラッグのあいだは、そのタスクが端になる線だけ、離したときに入る日付で色を追従させ、線はそのバーの見た目の位置に付いてくる。他のタスクの線の色と位置は変えない。絞り込みで見えている行は、離して確定するまで変えない。

**制約** 「前後: 破綻のみ」のときは、破綻している線だけを描く。追随する線は破綻の赤にしない。

### VIEW-09 非稼働日

**操作** 日表示または週表示の背景を見る。

**挙動** 非稼働日を薄い灰色で塗る。カレンダー未設定なら土日、設定済みなら [データ仕様](data-format.md#稼働日カレンダー-jsonschemaversion-1) の判定に従う。HTML と SVG の書き出しも同じである。

**制約** 月表示では日ごとに塗らない。バーの移動と期間は暦日のままである。

### VIEW-10 担当の表示

**操作** タスク行の右側を見る。

**挙動** 解決できたメンバーは表示名を出す。同じ表示名が複数あるときだけ ID を添える。割り当てなしは「割り当てなし」と破線の枠、上端の黄色で示す。メンバー不明は「メンバー不明」と ID、点線の紫の枠、上端の紫で示す。期限超過の赤は、これらの色より優先する。

**制約** 使用中カタログが無いとき、ID がある担当はすべてメンバー不明になる。

### VIEW-11 ノートアイコン

**操作** タスク行の左のノートアイコンを見る。

**挙動** ノートがあるタスクと無いタスクで色を分ける。押すとノートの全文をダイアログで開く。行の選択は変わらない。空のときは「ノートはありません」と出す。

**制約** ノート本文は行に常時出さない。

### VIEW-12 確度

**操作** タスクのバーと、左のタスク行と、マイルストンのひし形を見る。

**挙動** 確定のバーはベタ塗りである。未確定のバーは、同じステータス色の地に斜線を重ねる。斜線は、ライトでは地より濃く、ダークでは地より明るく、地の色が残る間隔である。左の行には「未確定」と出す。マイルストンの「超過」もあるときは、「未確定」「超過」の順で両方出す。「未確定」は超過の赤バッジとは別の見た目である。確定のマイルストンはひし形を塗りつぶす。未確定のマイルストンは、同じ色の地に同じ斜線を重ねる。HTML と SVG の書き出しも、同じ斜線と「未確定」を出す。

**制約** 枠の線種、上端の色、進捗の濃い帯、期限超過の赤は変えない。進捗の濃い帯は斜線の上にベタで描く。親バーと前後の線は、タスクの確度では変えない。マイルストンのひし形は、そのマイルストン自身の確度で変える。確度は着手や進捗とは独立である。

### NAV-01 スクロール

**操作** チャートをドラッグする。ホイール、または Shift+ホイールを回す。⌘ または Ctrl を押しながら矢印キーを押す。

**挙動** 修飾キーを押さないドラッグは、縦横にスクロールする。チャート本体の上では、ホイールで縦、Shift+ホイールで横に動く。日付ヘッダーとマイルストン帯の上では、ホイールで横に動く。⌘ または Ctrl と矢印では、上で縦に戻り、下で縦に進む。左で日付を過去へ、右で未来へ動かす。縦は左の一覧とチャートが一緒に動く。上下は 1 行分、左右はその行と同じ画面上の距離だけ動く。キーを押しているあいだは連続して動く。端では止まる。右クリックメニューが開いていれば閉じる。

**制約** ⌘/Ctrl を押したドラッグはスクロールではなく、タスクバーの移動になる。3px 未満の動きはスクロールとみなさない。修飾キーの無い矢印キーではチャートを動かさない。Shift または Alt を一緒に押しているときは、矢印では動かさない。検索欄、選択欄、ボタンにフォーカスがあっても、⌘ または Ctrl と矢印はチャートを動かす。ダイアログが開いているあいだは動かない。Mac では Ctrl+矢印が OS に取られて届かないことがある。届いた ⌘ または Ctrl は同じ動きにする。スケジュールのデータ、取り消し履歴、選択、絞り込みは変わらない。ドラッグ、ホイール、Shift+ホイールの動きは変えない。線を引くモードのあいだは、チャート上のドラッグでスクロールも移動も期間変更もひし形の日付変更もしない。ホイール、Shift+ホイール、⌘ または Ctrl と矢印は、モード中もスクロールする。

### NAV-02 ズームと日・週・月の切り替え

**操作** Ctrl または ⌘ を押しながらホイールを回す。− と ＋ を押す。

**挙動** マウスポインタの位置を基準に、1日あたりの幅を約1.15倍ずつ変える。幅が 40px 以上なら「日表示」、10px 以上 40px 未満なら「週表示」、それ未満なら「月表示」と見出しに出す。

**制約** 幅は 3px 以上 90px 以下。既定は 22px で週表示になる。このズームは、設定の表示サイズとは別である。

### NAV-03 Fit

**操作** 「Fit」を押す。ファイルを開いた直後も同じ処理が走る。

**挙動** 表示中の全期間がチャート幅に入るよう1日あたりの幅を決め、横位置を先頭に戻す。

**制約** 幅の上下限は NAV-02 と同じである。下限に当たると、全期間が入り切らないことがある。

### NAV-04 折りたたみ

**操作** カテゴリまたはグループの左の三角を押す。

**挙動** 配下の行を隠す。もう一度押すと戻す。畳んでもその行と親バーは残る。追加したタスクのカテゴリとグループは、追加時に展開する。

**制約** 折りたたみは取り消し履歴に入らない。ファイルを開くとすべて展開に戻る。

### NAV-05 名前の横ずらし

**操作** 左の名前が幅に収まらないとき、その名前を横にドラッグする。

**挙動** 見えている範囲の中で名前をずらし、続きを読めるようにする。データは変わらない。

**制約** 収まっている名前はドラッグできない。担当と「超過」は動かない。

### NAV-06 左一覧の幅

**操作** 左の一覧とチャートの境界を横にドラッグする。境界をダブルクリックするか、境界にフォーカスして左右キーを押しても変えられる。⌘ または Ctrl を押した左右キーでは変えない。

**挙動** 一覧の幅が変わり、チャートは残った幅に合わせて縮む。幅は表示倍率に比例し、表示倍率 1 のときの既定は 190px である。離した幅は localStorage に残り、次の起動でも使う。ダブルクリックは既定に戻し、保存した幅を消す。左右キーは、見えている幅を基準に、基準幅を 8 ずつ動かす。⌘ または Ctrl が付いているときは幅を変えず、NAV-01 のとおり横にスクロールする。そこに Shift または Alt も一緒のときは、幅もスクロールも変えない。ドラッグも左右キーも、表示幅が変わらないときは覚えている幅を変えない。ウィンドウを狭めてチャートが 200px を下回りそうなときは、その場の表示だけ縮め、覚えている幅は残す。広げ直すと、その幅に戻る。

**制約** 利用者が指定する基準幅は 140 未満にしない。チャート側は 200px 未満にしない。スケジュールのデータと取り消し履歴は変わらない。名前の横ずらしは、名前の上のドラッグのままである。書き出しのラベル幅は、画面の一覧幅とは別に、名前が収まる長さで決める。

### FILTER-01 タスク名

**操作** 「タスク名で検索」に文字を入れる。⌘/Ctrl+F でその欄へ移し、入っている文字を選択する。

**挙動** 名前にその文字を含むタスクだけを残す。前後の空白は除いて比べる。

**制約** 大文字小文字は区別する。絞り込みを変えると選択は外れる。

### FILTER-02 ノート

**操作** 「ノートで検索」に文字を入れる。

**挙動** ノートにその文字を含むタスクだけを残す。ノートが無いタスク、空白だけのノートは残さない。タスク名の検索と併用したときは、両方を満たすタスクだけが残る。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-03 担当者

**操作** 「担当者」で「すべて」「割り当てなし」、またはメンバーを選ぶ。

**挙動** 「割り当てなし」は、割り当てなしとメンバー不明の両方を残す。特定のメンバーは、その ID のタスクだけを残し、メンバー不明は出さない。カタログが変わり、選んでいた ID が消えると「すべて」に戻る。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-04 ステータス

**操作** 「ステータス」で「すべて」「完了以外」「未着手」「進行中」「完了」を選ぶ。

**挙動** 「完了以外」は `done` 以外を残す。ほかは、そのステータスだけを残す。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-05 期限

**操作** 「期限」で「すべて」か「期限超過」を選ぶ。

**挙動** 「期限超過」は VIEW-05 のタスクだけを残す。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-06 前後

**操作** 「前後」で「すべて」か「前後: 破綻のみ」を選ぶ。

**挙動** 「前後: 破綻のみ」は、破綻している線の両端のタスクだけを残す。線の見た目は VIEW-08 に従う。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-07 マイルストン

**操作** 「マイルストン」で「すべて」「なし」、またはマイルストンを選ぶ。

**挙動** 「なし」は対応マイルストンが無いタスクだけを残す。特定のマイルストンは、それを指すタスクだけを残す。選んでいたマイルストンが消えると「すべて」に戻る。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-08 系統

**操作** タスクを選んで「系統」を押す。もう一度押すと解除する。右クリックメニューの「系統を表示」は、そのタスクを起点にする。すでにそのタスクが起点なら「系統を解除」になる。

**挙動** 起点から先行と後続をたどれるところまでたどり、そのタスクだけを残す。起点を通らない枝は含めない。ボタンには起点の名前を出す。別のタスクが起点のときに「系統を表示」を選ぶと、起点をそのタスクへ切り替える。ツールバーの「系統」は、起点があるあいだは解除だけをする。タスクを追加したとき、または起点のタスクを削除したときは解除する。

**制約** タスクを選んでいないときは押せない。絞り込みを変えても系統自体は外れないが、選択は外れる。系統は取り消し履歴に入らない。

### FILTER-09 組み合わせと空のグループの省略

**操作** 複数の絞り込みと折りたたみ、系統を同時に使う。

**挙動** タスクはすべての条件を満たすものだけが残る。残ったタスクが無いグループとカテゴリは行から省く。折りたたみは、残った行をさらに隠す。前後の線は、両端が行として見えているときだけ描く。

**制約** 省いたグループとカテゴリはデータに残り、追加ダイアログでは選べる。

### FILTER-10 確度

**操作** 「確度」で「すべて」「未確定」「確定」を選ぶ。

**挙動** 「未確定」は `tentative` だけを残す。「確定」は `committed` だけを残す。

**制約** 絞り込みを変えると選択は外れる。ステータスや進捗では判定しない。

### EDIT-01 選択

**操作** タスクバーをクリックする。背景をクリックすると解除する。タスクの行またはバーを右クリックすると、そのタスクを選択する。

**挙動** 選択したバーに期間変更のハンドルを出す。「削除」が押せるようになる。追加に成功すると、そのタスクを選択して見える位置へスクロールする。

**制約** 左の行を左クリックしても選択されない。絞り込みの変更、削除、別ファイルを開くと選択は外れる。スクロールと判定したドラッグでは選択を変えない。

### EDIT-02 移動

**操作** ⌘ または Ctrl を押しながらタスクバーを横にドラッグし、離す。

**挙動** 開始日と終了日を、ドラッグした日数だけ動かす。縦には動かない。ドラッグを始めたときから離すまで、開始日と終了日を両方、`4/3` のように月と日だけで出す。年と曜日は出さない。数字は、離したときに入る日に合わせる。文字の大きさは、チャートのズームではなく画面の表示倍率に従う。文字は不透明な地の上に書き、チャートの背景が文字に透けないようにする。地は、動かしている棒、もう一方の日付の地、見えている他の棒には重ねない。空いているときは各端の上に置き、重なるときや画面の端では、棒の外側へずらして画面内に収める。離すと日付は消える。離したときに1回だけ確定し、取り消しの1ステップになる。

**制約** 修飾キーが無いドラッグはスクロールで、日付は出さない。期間の長さは変わらない。確度は変わらない。名前の横ずらし、マイルストンのひし形、親バーには出さない。開始日や終了日が非稼働日でも印は出さない。バーの長さは暦日のままである。

### EDIT-03 期間変更

**操作** 選択したバーの左端または右端を横にドラッグし、離す。

**挙動** 左端は開始日、右端は終了日を変える。ドラッグ中は、開始日と終了日の両方を EDIT-02 と同じ置き方で出す。1日より短くならない位置で止まった日付を出す。離したときに1回だけ確定する。

**制約** 期間は1日未満にできない。終了日は開始日より前にできない。確度は変わらない。修飾キーの無いチャートのドラッグでは日付を出さない。

### EDIT-04 編集ダイアログ

**操作** タスクバーをダブルクリックする。選択中に Enter を押すか、右クリックメニューの「編集」でも開く。

**挙動** タスク名、ノート、開始日、終了日、担当者、ステータス、進捗率、確度、対応マイルストン、先行、後続を編集できる。保存するとスケジュールに反映し、取り消しの1ステップになる。キャンセルや Escape では反映しない。

**制約** タスク名は必須。日付は実在する日で、終了日は開始日以降。進捗率は 0 以上 100 以下の整数。循環する前後関係や、存在しない先行は保存せず、理由を出す。ダイアログを開いているあいだは背面を操作できない。

### EDIT-05 前後関係

**操作** 編集ダイアログの先行と後続でタスクを足す、または外す。

**挙動** 先行に足したタスクの ID は、自分の `predecessors` に入る。後続に足すと、相手の `predecessors` に自分の ID が入る。候補は名前で絞れ、自分自身は出さない。先行にいるタスクは後続の候補から外し、後続にいるタスクは先行の候補から外す。選択済みは、カテゴリとグループを1行、タスク名を次の行に出す。長い階層はカテゴリとグループの行だけを省略する。ホバーでは「カテゴリ / グループ / タスク名」の全文が出る。見つからない ID は `ID` と ID の1行で、ホバーも同じ文字列である。

**制約** 候補は一度に50件までである。それを超えると「さらに絞り込んでください」と出す。

### EDIT-06 ノート

**操作** ノートアイコン、編集ダイアログのノート欄、または右クリックメニューの「ノート」から保存する。

**挙動** 書いた内容をタスクの `note` にする。空白だけを保存するとプロパティを消す。確定すると取り消しの1ステップになる。

**制約** 空のノートは JSON に書かない。

### EDIT-07 マイルストン

**操作** 「マイルストン追加」で名前、日付、確度を指定して足す。マイルストンが 0 件で帯が無いときでも押せる。ひし形を横にドラッグする。ダブルクリック、または右クリックメニューの「編集」で名前、日付、確度を編集する。ひし形の右クリックメニューの「削除」で確認して消す。

**挙動** 追加ダイアログの名前の初期値は空、日付の初期値は画面の今日、確度の初期値は未確定である。追加は配列の末尾に1件足す。日付順には並べ替えない。同じ名前と日付でも足せる。保存する名前は前後の空白を除いたものである。ID は、そのスケジュールのカテゴリ、グループ、タスク、マイルストンの ID のどれとも重ならない UUID である。追加しても絞り込み、折りたたみ、ズーム、スクロール、系統、選択は変えない。ドラッグは日付を日単位で変え、離したときに確定する。ドラッグでは確度は変えない。編集ダイアログでは名前、日付、確度を変える。日付が空なら保存しない。名前が空白だけなら、元の名前を残す。削除はマイルストンを配列から外し、その ID を指すタスクの `milestoneId` をすべて外す。タスクの日付、先行、ステータス、進捗、ノートは変えない。空のグループとカテゴリは残す。見えていないタスクも含め、その ID を指すタスクが1件でもあれば、確認に「このマイルストンを指しているタスクの対応は外れます。タスクの日付は変えません。」を出す。無ければその文は出さない。絞り込んでいたマイルストンを消したときだけ、マイルストンの絞り込みを「すべて」に戻す。「なし」と「すべて」と別のマイルストンはそのままである。選択と系統と折りたたみは変えない。追加と削除は、それぞれ取り消しの1ステップである。絞り込みを「すべて」に戻すことは履歴に入らない。取り消しても絞り込みは「すべて」のままである。

**制約** 名前が空白だけなら「名前を入力してください」、日付が空または実在しない日なら「日付を入力してください」と出し、追加しない。ダイアログは開いたままにする。キャンセルと Escape では足さない。ツールバーの「追加」と「削除」、Delete、Backspace はタスクのままである。確認をキャンセルすると消さない。

### EDIT-08 追加

**操作** 「追加」を押し、カテゴリ、グループ、タスク名、開始日、終了日を指定する。

**挙動** 選んだグループの末尾にタスクを足す。選択中のタスクがあれば、そのカテゴリ、グループ、日付を初期値にする。無ければ先頭のカテゴリとグループ、今日の日付を使う。新しいタスクは割り当てなし、未着手、進捗 0、未確定、前後関係なし、対応マイルストン未設定で、ID は、カテゴリ、グループ、タスク、マイルストンの ID と重ならない新しい UUID である。追加後はその行が見えるよう展開し、系統を解除し、そのタスクを選択する。

絞り込みは、新しいタスクを隠してしまうものだけを外す。

- 担当者: 特定のメンバーなら「すべて」に戻す。「割り当てなし」はそのまま残す
- ステータス: 「完了」か「進行中」なら「すべて」に戻す。「完了以外」と「未着手」はそのまま残す
- 確度: 「確定」なら「すべて」に戻す。「未確定」と「すべて」はそのまま残す
- 期限: 「期限超過」で、新しいタスクが期限超過でなければ「すべて」に戻す
- 前後: 「前後: 破綻のみ」は外す
- マイルストン: 特定のマイルストンなら「すべて」に戻す。「なし」はそのまま残す
- タスク名の検索: 新しい名前に含まれない文字なら消す
- ノートの検索: 文字が入っていれば消す

**制約** 終了日が開始日より前なら追加しない。期間は1日未満にできない。空のグループとカテゴリも追加先として選べる。

### EDIT-09 削除

**操作** タスクを選んで「削除」を押すか、Delete または Backspace を押し、確認する。右クリックメニューの「削除」でも同じ確認を開く。

**挙動** そのタスクを消す。他のタスクの先行からはその ID を外し、前後のタスク同士はつながない。系統の起点を消したときは系統を解除する。空になったグループとカテゴリはデータに残す。線の上で Delete または Backspace を押したときは、タスクは消さず、EDIT-12 のとおりその線だけを外す。

**制約** タスクを選んでいないと「削除」は押せない。確認をキャンセルすると消さない。検索欄、入力欄、選択欄、ボタンにフォーカスがあるときは、Delete と Backspace では消さない。ツールバーの「削除」は、線の上でもタスクを消す。

### EDIT-10 取り消し・やり直し

**操作** ⌘/Ctrl+Z で取り消す。⌘/Ctrl+Shift+Z、または Ctrl+Y でやり直す。

**挙動** カテゴリ、グループ、タスク、マイルストンの確定した変更を1操作1ステップで戻す。対象はバーの移動、期間変更、マイルストンの移動、編集ダイアログの保存、ノートの保存、確度の切り替え、カテゴリとグループの改名、追加、削除、チャート上で線を足すこと、線を1本外すことである。最大100件まで覚える。ファイルを開くと履歴は空になる。

**制約** タイトル、絞り込み、折りたたみ、ズーム、スクロール、系統、選択は履歴に入らない。ダイアログ、検索欄、入力欄にフォーカスがあるときは、取り消し・やり直しのキーはスケジュールに効かない。同じ内容の変更はステップに積まない。

### EDIT-11 右クリックメニュー

**操作** タスクのバー、または左のタスク行を右クリックする。マイルストンはひし形を右クリックする。左のカテゴリ行とグループ行も右クリックする。

**挙動** タスクでは「編集」、今の確度と逆の「確定にする」または「未確定にする」、「ノート」、「系統を表示」または「系統を解除」、「削除」を出す。確度の切り替えは日付を動かさず、取り消しの1ステップである。右クリックしたタスクを選択する。マイルストンでは「編集」、今の確度と逆の「確定にする」または「未確定にする」、「削除」を出す。確度の切り替えは日付を動かさず、取り消しの1ステップである。右クリックしても選択しない。左のカテゴリ行とグループ行では「名前を変更」だけを出し、選ぶと EDIT-13 のダイアログが開く。見えている線の上では「線を外す」だけを出す。メニューはクリック位置に出し、画面の端では内側へずらす。項目を選ぶ、外側をクリックする、Escape、スクロール（⌘/Ctrl+矢印を含む）、またはダイアログが開くと閉じる。選択中バーの端のハンドルでも、バーと同じメニューが出る。削除は確認を開く。線を外すは確認しない。系統は FILTER-08 のとおりである。線を外すは EDIT-12 のとおりである。

**制約** チャートの空白では出さない。ダイアログを開いているあいだは背面を操作できないので出ない。線を引くモードのあいだは、タスク、ひし形、カテゴリ行、グループ行のメニューは出さない。線の「線を外す」は出す。タスクバーとひし形は、線より先に当たる。

### EDIT-13 カテゴリとグループの名前

**操作** 左のカテゴリ行またはグループ行をダブルクリックする。右クリックの「名前を変更」でも同じ。

**挙動** 名前だけのダイアログが開く。保存する名前は前後の空白を除いたものである。空白だけなら、元の名前を残して閉じる。カテゴリ名が他のカテゴリと重なるとき、または同じカテゴリの中でグループ名が重なるときは、保存せず、重複であることを示す。保存すると `id` は変わらず、名前だけが変わる。取り消しは 1 ステップである。折りたたみは `id` を鍵にするので、改名しても開閉は残る。絞り込み、ズーム、スクロール、系統、選択は変えない。

**制約** カテゴリやグループの追加、削除、タスクを別のグループへ移す操作はしない。チャート上の親バーからは開かない。線を引くモードのあいだは開かない。

### EDIT-12 チャート上の前後の線

**操作** タスクを選んで「線を引く」を押す。⌘/Ctrl+L でも同じ。別のタスクバーをクリックすると、起点からそのタスクへ線を足す。起点をもう一度クリックする、Esc、「線を引く」、または ⌘/Ctrl+L で、結ばずに終わる。線にカーソルを合わせて Delete または Backspace を押すか、線を右クリックして「線を外す」を選ぶと、その 1 本を外す。

**挙動** 選んでいないときはモードに入らない。入るとボタンに起点の名前が出て、画面上部は「次にクリックしたタスクを後続にします。Esc で中止」になる。起点は入ったときのタスクのままである。起点の右端からカーソルへ、確定した矢印と同じ折れ線が通常の色で追随する。タスクバーの上ではそのバーの左端まで伸び、左の一覧の上ではチャートの左端で終わる。モードを終えると消える。カーソルが乗ったタスクバーは、選択の枠とは別の輪郭になる。起点、親バー、ひし形は強調しない。別のタスクバーをクリックすると、後続の `predecessors` に起点が入り、取り消しの 1 ステップになる。モードは残る。すでに結ばれている組と循環する組は保存せず、編集ダイアログと同じ理由をモードのヒントの下に出す。モードは残る。線を外すときは確認せず、その先行だけを外し、取り消しの 1 ステップになる。タスクは残り、前後のタスク同士はつながらない。重なった線は、カーソルに一番近い 1 本だけを太くして外す。

**制約** 見えていないタスクへは、この操作では線を引けない。編集ダイアログの先行と後続は今どおり使える。モード中、チャートのドラッグはスクロールも移動も期間変更もひし形の日付変更もしない。ホイール、Shift+ホイール、⌘ または Ctrl と矢印ではスクロールでき、追随する線も動く。親バー、ひし形、背景のクリックではモードは終わらない。ダブルクリックと Enter では編集ダイアログを開かない。タスクとひし形の右クリックメニューは出さない。左の名前の横ずらしと一覧の幅は今どおりである。絞り込み、起点の削除、別ファイルを開くなどで選択が外れるとモードも終わる。⌘/Ctrl+L は、ダイアログ、検索欄、入力欄、選択欄では効かない。ボタンにフォーカスがあっても効く。修飾キーの無い L では始まらない。線の上の Delete と Backspace は、検索欄、入力欄、選択欄、ボタンにフォーカスがあるときは線を外さない。バーやひし形の上では、今どおりタスクの削除確認である。両端が見えていない線は描けないので、この操作では外せない。ツールバーの「削除」はタスクを消す。線の端をドラッグして付け替えない。スキーマは変えない。

### EXPORT-01 形式

**操作** ☰ の「書き出し」で HTML か SVG を選び、「書き出す」を押す。

**挙動** 選んだ形式のファイルを保存する。既定の選択は HTML である。キャンセルでは何も書かない。

**制約** 生成はフロントで行い、画面の Canvas を画像化しない。

### EXPORT-02 対象の行と期間

**操作** 絞り込み、折りたたみ、系統を使った状態で書き出す。

**挙動** 見えている行を、スクロールで隠れている分も含めて書く。期間は、その行と書き出すマイルストンから決め直し、前後に画面と同じ余白を付ける。1日あたりの幅と、日・週・月の粒度は画面と同じである。前後の線、イナズマ線、非稼働日、親バー、超過、使っている絞り込みの一覧も入れる。

**制約** 画面全体の期間や、隠れているタスクは入れない。マイルストンの選び方は [データ仕様](data-format.md#書き出しファイル) のとおりである。

### EXPORT-03 上限

**操作** 大きいスケジュールを書き出す。

**挙動** 行数が 10,000 を超える、幅が 200,000px を超える、または高さが 50,000px を超えるときは、ファイルを書かずに理由を出す。デスクトップ版は、できた内容が 10MB を超えるときも保存しない。

**制約** 上限を超えたときは、絞り込みや折りたたみで対象を減らす。

### EXPORT-04 ファイル名

**操作** 保存ダイアログに出る提案名を見る。

**挙動** スケジュールのタイトルから、パスに使えない文字と制御文字を除いた名前に `.html` または `.svg` を付ける。空、または Windows の予約名だけなら `schedule` を使う。

**制約** デスクトップ版は保存ダイアログで名前を変えられる。ブラウザ版はダウンロード名になる。

### SET-01 表示サイズ

**操作** 設定の「表示」で「自動」「50%」「75%」「100%」「125%」「150%」「200%」を選ぶ。

**挙動** 文字、行、ボタンの大きさを変える。「自動」は、幅 1100px、高さ 780px を基準に、それより大きいウィンドウで最大 200% まで広げる。基準以下では 100% のままである。選んだ値は localStorage に残り、次の起動でも使う。「自動」に戻すと保存値は消える。

**制約** チャートのズーム（NAV-02）とは別である。固定値は 50% 未満、200% 超にはできない。

### SET-04 配色

**操作** 設定の「表示」で「システム設定に合わせる」「ライト」「ダーク」を選ぶ。

**挙動** 画面全体の色を変える。ライトは従来どおりの明るい配色である。ダークは暗い灰を基調にし、文字と区切りが読める配色にする。HTML と SVG の書き出しは、書き出した時点の画面と同じ配色にする。「システム設定に合わせる」では OS の明るさ設定（`prefers-color-scheme`）に従い、ダークならダーク、それ以外はライトにする。この選択中に OS の設定が変わったら、再起動しなくても画面を追従させる。「ライト」と「ダーク」は OS の設定より優先する。選んだ値は localStorage に残り、次の起動でも使う。「システム設定に合わせる」に戻すと保存値は消える。

**制約** チャートのズーム（NAV-02）と表示サイズ（SET-01）とは別である。スケジュール JSON には書かない。

### SET-02 メンバー

**操作** 設定の「メンバー」で、「取り込み…」でカタログを足す。一覧のラジオボタンで使うカタログを選ぶ。「選択を解除」で未選択に戻す。各カタログの「外す」で消す。

**挙動** メンバー JSON を検証してカタログとして保存する。カタログの ID はファイル名から作り、同じ ID のカタログが既にあるときは上書きを確認する。使用中のカタログ名は、設定と見出しに出る。「外す」はそのカタログを消し、使用中だったなら未選択に戻す。初回はサンプルのメンバーを一度だけ入れる。削除したあとは、自動では戻さない。

**制約** スケジュール JSON にはメンバーを書かない。デスクトップ版の1件の上限は 2MB。読み込みに失敗すると見出しに「メンバー設定エラー」を出す。

### SET-03 稼働日

**操作** 設定の「稼働日」で「取り込み…」または「外す」を押す。

**挙動** カレンダー JSON を1件だけ保存する。既にあるときは上書きを確認する。未設定のときは「使用中: 未設定（土日を塗る）」と出る。外すと未設定に戻る。検証や読み込みに失敗したときは土日表示に戻し、見出しに「カレンダー設定エラー」を出す。

**制約** スケジュール JSON には書かない。タスクの日付は暦日のままである。デスクトップ版の上限は 2MB。

## ダイアログ

共通の枠は Escape で閉じ、フォーカスをダイアログ内に留める。開いているあいだは背面を操作できない。

| ダイアログ | 出る条件 | 選択肢と結果 |
| --- | --- | --- |
| タスクの編集 | バーのダブルクリック、選択中の Enter、右クリックの「編集」 | 保存で反映。閉じると破棄 |
| ノート | ノートアイコン、右クリックの「ノート」 | 保存でノートを更新。空白だけなら削除 |
| マイルストンの編集 | ひし形のダブルクリック、右クリックの「編集」 | 保存で名前と日付を更新 |
| マイルストンの追加 | 「マイルストン追加」 | 名前と日付が有効なら末尾に追加。無効なら開いたまま |
| タスクの追加 | 「追加」 | 条件を満たせば末尾に追加 |
| タスク削除 | 「削除」、Delete、Backspace、右クリックの「削除」 | 「削除」で消す。「キャンセル」で残す |
| マイルストン削除 | ひし形の右クリックの「削除」 | 「削除」で消し、指しているタスクの対応を外す。「キャンセル」で残す |
| 設定 | ☰ の「設定」 | 表示（サイズと配色）、メンバー、稼働日を変える。メンバーとカレンダーの上書き確認は設定の中に出る |
| JSON | ☰ の「JSON を表示」 | 閉じるだけ |
| 差分 | ☰ の「差分を表示」 | 「コピー」で全文を写す。「閉じる」で閉じる。ファイルは増えない |
| 書き出し | ☰ の「書き出し」 | HTML か SVG を選んで「書き出す」 |
| スケジュールを読み込めません | 検証、監視、控え、書き出しの失敗 | 「閉じる」。タイトルは失敗の種類で変わることがある |
| 未保存の変更 | 未保存で別ファイルを開く。サンプルの未保存で閉じる | 「破棄して開く」または閉じるときの破棄。「キャンセル」で中止 |
| ファイルが更新されています（保存時） | 保存直前にディスクが変わっている | 「上書き保存」「別名保存」「取り消し」 |
| ファイルが更新されています（監視） | 外部更新があり、未保存か編集中 | 「読み直す」「画面の編集を残す」 |
| 前回の未保存の編集 | 起動時、控えとディスクが違う。またはファイルが無く未保存がある | 「ファイルを開く」「未保存の編集を戻す」 |
| ファイルが見つかりません | 起動時、前回のファイルが無く未保存も無い | 「閉じる」。サンプルにする |
| 復旧用の控え | 控えが壊れている、またはファイルはあるが検証できない | 「閉じる」「控えを破棄」 |

## 上限値

| 項目 | 値 |
| --- | --- |
| スケジュールの読み書き、書き出しの保存、控え | 10MB（デスクトップ版） |
| メンバー 1件、カレンダー | 2MB（デスクトップ版） |
| 取り消し | 100件 |
| 先行・後続の候補表示 | 50件 |
| 書き出しの行、幅、高さ | 10,000 行、200,000px、50,000px |
| 1日あたりの幅 | 3〜90px。既定 22px。40px 以上で日表示、10px 以上で週表示 |
| 左一覧の基準幅 | 140px 以上。既定 190px。チャート側は 200px 以上。表示倍率を掛ける |
| 表示サイズ | 50%、75%、100%、125%、150%、200%、または自動 |
| 配色 | システム設定に合わせる、ライト、またはダーク |
| 外部更新の確認間隔 | 1.5秒 |
| 「ファイルを反映しました」の表示時間 | 4秒 |
| 監視の読み取り失敗 | 連続5回でファイルダイアログ |
| 控えを書くまで | 変更から約1秒。閉じる直前は待たない |
| タイムラインの余白 | 最も早い日付の6日前から、最も遅い日付の7日後まで |
