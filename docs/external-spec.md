# 外部仕様

画面と機能の挙動を定める。正本はソースコードで、挙動を変えたらこの文書も直す。利用者向けの手順は [操作マニュアル](user-manual.md)、ファイルの形は [データ仕様](data-format.md) にある。

機能 ID は `FILE-01` の形である。テスト仕様は、この ID で自動テストと手動テストケースを対応づける。

## スコープ

アプリは、検証済みのスケジュール JSON を表示し、絞り込み、編集し、書き出す。次のことはしない。

- 稼働日を踏まえた期間の計算や、前後関係に合わせた日付の自動変更
- LLM への接続。スケジュール、メンバー、カレンダーの生成は、アプリの外のスキルが行う

## 用語

| 用語 | 意味 |
| --- | --- |
| カテゴリ | スケジュールの最上位のまとまり。識別子は `id` で、名前は表示である |
| グループ | カテゴリの中のまとまり。識別子は `id` で、名前は同じカテゴリの中で重複できない |
| タスク | 開始日と終了日を持つ作業。終了日はその日を含む |
| マイルストン | 名前、日付、確度を持つ時点。タスクではない |
| 対応マイルストン | タスクの `milestoneId` が指すマイルストン。タスクごとに0件か1件で、詳細パネルの「対応マイルストン」で選ぶ |
| 先行・後続 | タスクの `predecessors` が指す相手が先行、自分を指している相手が後続 |
| 破綻 | 後続の開始日が、先行の終了日より前であること。同じ日に始まる場合は破綻にしない |
| 期限超過 | 完了以外で、終了日が今日より前であること。終了日が今日なら超過にしない |
| マイルストン超過 | 対応マイルストンがあり、終了日がその日付より後であること。当日は超過にしない |
| 割り当てなし | `assigneeId` が `null` であること |
| メンバー不明 | `assigneeId` があるが、使用中のカタログにその ID が無いこと。カタログ未選択も含む |
| カタログ | 設定に取り込んだメンバー JSON の1件 |
| 系統 | 選んだタスクから、先行をそれ以上さかのぼれないところまで、後続をそれ以上たどれないところまでつないだ範囲。起点を通らない枝は含めない |
| 親バー | カテゴリまたはグループの期間を示す、タスクバーより低いバー |
| イナズマ線 | 今日の進み方を示す折れ線。遅れや先行を、行の端まで折って示す |
| 非稼働日 | カレンダーの規則、または未設定時の土日。表示だけに使い、日付の計算には使わない |
| 控え | 未保存の内容を、開いている JSON ファイルとは別にアプリデータへ残したもの |
| サンプルデータ | ファイルを開いていないときの起動用スケジュール |
| 見出し | 画面左上のタイトルと、その右に並ぶ状態の表示をまとめたもの |

## 動作環境

配布物は Ubuntu 22.04 以降の deb と、Windows の NSIS インストーラである。macOS は、使う Mac の上でビルドしたアプリを使う。ビルドの手順は [開発ガイド](development.md#配布用ビルド) にある。

Tauri で作ったデスクトップアプリをデスクトップ版、`npm run dev` でブラウザに開いたものをブラウザ版と呼ぶ。違いは次のとおりである。

| 操作 | デスクトップ版 | ブラウザ版 |
| --- | --- | --- |
| 開く | OS のファイルダイアログ | ファイル選択 |
| 保存、別名保存、書き出し | OS の保存ダイアログ | ダウンロード |
| 外部の更新の監視 | 開いているファイルを約1.5秒ごとに見る | しない |
| 復旧用の控え | 未保存のときアプリデータに書く | しない |
| 前回開いたファイル | 開いていたウィンドウ一覧とパスを覚え、次回それぞれを開く | しない |
| 別ウィンドウ | 同じアプリでスケジュールを複数開ける。2つ目のアプリは起動しない | ウィンドウを増やさない |
| ウィンドウを閉じる | 未保存なら控えを書くか、サンプルなら確認する。終了は開いているウィンドウすべてに同じ確認を通す | ブラウザ標準の離脱確認 |
| メンバーとカレンダー | アプリデータ（デスクトップ版では変更を他のウィンドウへ知らせ、読み直す） | localStorage |
| 表示サイズ、配色、左一覧の幅 | localStorage（デスクトップ版では開いているウィンドウで同じ値） | localStorage |
| 行の密度、イナズマ線、一覧の列 | localStorage（デスクトップ版では開いているウィンドウで同じ値） | localStorage |
| 読み書きの上限 | スケジュールと書き出しは 10MB、メンバーとカレンダーは 2MB | 同じ上限 |

## 画面構成

```
+--------------------------------------------------------------------------------------------+
| ☰  タイトル [状態]  [名前|ノート] 検索  絞り込み              今日 日週月 全体  ? |
| 系統  線を引く  追加  マイルストン追加  削除  取り消し  やり直し                      |
| [担当: 佐藤 ×] [期限超過 ×]  すべて解除   （条件があるときだけ）                          |
+--------------------------+-----------------------------------------------------------------+
| WBS / タスク             | 日付ヘッダー                                                    |
| マイルストン             | マイルストン帯                                                  |
| カテゴリ / グループ /    | 親バー、タスクバー、前後の線、イナズマ線                        |
| タスク                   |                                                                 |
+--------------------------+-----------------------------------------------------------------+
```

画面上部のツールバーは2段である。上段に ☰、見出し、検索、絞り込み、今日と日・週・月・全体とショートカット一覧の入口を並べ、下段に系統、線を引く、追加、マイルストン追加、削除、取り消し、やり直しを並べる。各ボタンのラベルは折り返さない。検索は1つの欄で、欄の左で「名前」か「ノート」を切り替える。絞り込みの担当者、ステータス、確度、期限、前後、マイルストンは「絞り込み」ボタンで開くパネルにまとまる。ボタンには、効いている条件の数を出す。条件が1つでもあるとき、または系統が効いているときは、その下に外せる札を並べる。「すべて解除」は絞り込みだけを初期値に戻し、系統は外さない。線を引くモードのあいだだけ、チャートの上端に1行の帯を出す。操作の一覧は、? キー、F1、☰ の「ショートカット一覧」で開くダイアログにまとまる。⌘ または Ctrl と K で開くコマンドパレットから、同じ操作の多くを名前で探して実行できる。

左の行と右のチャートは、縦に一緒にスクロールする。タスクを選ぶと、チャートの右に詳細パネルが出る。詳細パネルは一覧とチャートより一段手前に浮かせて見せる。左一覧とチャートの境界を横にドラッグすると、一覧の幅を変えられる。左の幅に収まらない名前は、マウスを乗せると全文が出る。名前をドラッグしても動かない。担当、追加列、「超過」は動かない。追加列を出したときは、開始と終了を `09/19` のように月と日で、日数を `12日`、進捗を `30%` で出す。開始、終了、日数、進捗、超過、担当は、行をまたいで同じ位置に揃う。超過が無い行もその幅を空ける。担当が列の幅を超えるときは省略し、マウスを乗せると全文が出る。

☰ メニューの項目は「開く」「新しいウィンドウで開く」「保存」「別名保存」「書き出し」「JSON を表示」「差分を表示」「ショートカット一覧」「設定」である。「開く」「新しいウィンドウで開く」「保存」「別名保存」の右には、Mac では ⌘、それ以外では Ctrl のショートカットを出す。ファイル操作の途中は、開く、新しいウィンドウで開く、保存、別名保存、差分を表示を押せない。未保存のときは、画面下の状態バーの「未保存」を押しても差分ダイアログが開く。メニューは外側のクリックか Escape で閉じる。macOS のデスクトップ版では、画面上部のメニューバーにも同じファイル操作と、表示の切り替え、文字入力用の編集メニュー、ウィンドウメニュー（⌘W で閉じる、⌘M で最小化）を出す。編集の取り消しは、入力欄にフォーカスがあるときは文字入力の取り消し、それ以外はスケジュールの履歴を戻す。アプリメニューの終了は ⌘Q を割り当て、開いているウィンドウすべてに、ウィンドウを閉じる操作と同じ未保存確認を通る。

ダイアログが開いているあいだ、開く、新しいウィンドウで開く、保存、別名保存、タスク名の検索への移動、Enter で詳細パネルの名前欄へフォーカスを移す操作、Delete と Backspace での削除、線を引く、ノートを開く、⌘/Ctrl+矢印でのスクロール、? と F1 によるショートカット一覧の開き、⌘/Ctrl+K によるコマンドパレットの開きは効かない。コマンドパレットだけが開いているあいだは、同じ ⌘/Ctrl+K と Escape で閉じる。詳細パネルの入力欄にフォーカスがあるあいだも、外部ファイルの即時反映は止める。検索欄、入力欄、選択欄、ボタンにフォーカスがあるとき、開く、保存、別名保存、タスク名の検索への移動、⌘/Ctrl+矢印でのスクロール、⌘/Ctrl+K によるコマンドパレットの開きは効く。線を引く ⌘/Ctrl+L と、ノートを開く ⌘/Ctrl+N は、検索欄、入力欄、選択欄では効かず、ボタンでは効く。Enter と Delete と Backspace、修飾キーの無い矢印と L と N は、そのフォーカス先の操作のままにする。⌘/Ctrl+N は、開くときも、選択が無いなどで何もしないときも、ブラウザには渡さない。Shift 付きの N はアプリが取らない。表示サイズの ⌘ または Ctrl と +、=、− は、ダイアログが開いていても、検索欄、入力欄、選択欄、ボタンにフォーカスがあっても効く。? と F1 は、検索欄、入力欄、選択欄では効かない。

画面下の状態バーに、ファイル名、保存の状態、メンバーカタログ、表示の粒度、件数を出す。件数は「全件数中、表示件数を表示」の順である。保存の状態は、未保存のとき「未保存」（押すと差分ダイアログ）、保存済みのとき「保存済み」またはファイル名に応じた表示である。外部の反映のような一時的な知らせは、画面の隅に数秒だけ出る通知にする。別のウィンドウで同じファイルが更新されたときの知らせも同じ隅に出し、押すとそのウィンドウを前面に出す。アプリが他のソフトの後ろにあるときは、同じ内容を OS の通知でも出す。メンバーとカレンダーの設定エラーは状態バーに注意の色で出し、押すと設定の該当欄が開く。見出しのタイトル欄には、スケジュールのタイトルだけを出す。

### FILE-01 開く

**操作** ☰ の「開く」。⌘/Ctrl+O でも同じ。

**挙動** 選んだ JSON を検証し、通れば画面のスケジュールを置き換える。見出しはファイル名になる。絞り込み、折りたたみ、系統、選択、取り消し履歴は初期状態に戻し、期間が幅に収まるよう Fit する。検証に失敗したファイルは開かず、それまでの保存先も変えない。エラーは日本語で、場所はカテゴリ、グループ、タスクの名前で示す。

**制約** 未保存のときは、破棄して開くかキャンセルするかを先に選ぶ。ファイルの `note` が空白だけのときは読み込みエラーになる。画面でノートを空にして保存すると、その項目は消える。読み込み上限は 10MB。開けるのは schemaVersion 3、4、5、6 である。3 は、確度が無いタスクを確定として読む。4 は、カテゴリとグループに名前から決まる `id` を付ける。5 は、マイルストンが1件以上あるとき、名前「マイルストン」のグループを1つ足し、全部のマイルストンをそこへ入れる。マイルストンが0件なら、そのグループは空のままである。いずれも schemaVersion 6 にする。開いた直後の未保存の比較元は、その移行後の保存形式である。ディスク上の文字列とそのまま比べないので、開いただけでは未保存にならない。同じ 3、4、5 を開き直しても、付けた `id` は変わらない。保存すると schemaVersion 6 で、全部のタスクとマイルストンに `confidence` が入り、カテゴリとグループに `id` が入る。マイルストンがあるときは `milestoneGroups` と `groupId` も入る。マイルストンに確度が無い 3、4、5 は、そのマイルストンを確定として読む。schemaVersion 2 は開けない。ブラウザ版では「新しいウィンドウで開く」は出ない。

### WIN-01 新しいウィンドウで開く

**操作** デスクトップ版の ☰ の「新しいウィンドウで開く」。⌘/Ctrl+Shift+O でも同じ。コマンドパレットと macOS のファイルメニューからも選べる。

**挙動** 選んだ JSON を、今のウィンドウではなく新しいウィンドウで開く。今のウィンドウのスケジュールは残す。検証は今のウィンドウ側で行い、失敗したときは今のウィンドウにエラーを出し、ウィンドウは増やさない。通ったときだけ新しいウィンドウを作り、その内容を載せる。絞り込み、折りたたみ、系統、選択、取り消し履歴は新しいウィンドウだけ初期状態に戻し、期間が幅に収まるよう Fit する。同じパスは複数のウィンドウで開ける。

**制約** 未保存でも破棄の確認は出さない。ファイル操作の途中は押せない。⌘/Ctrl+Shift+O はデスクトップ版だけが取り、ブラウザ版はブラウザに渡す。ウィンドウの位置は覚えない。枚数の上限は置かない。

### FILE-02 保存

**操作** ☰ の「保存」。⌘/Ctrl+S でも同じ。

**挙動** 開いているパスがあれば、そのファイルへ今の内容を書く。無ければ別名保存と同じく保存先を選ぶ。成功すると未保存が外れ、控えは消える。

**制約** デスクトップ版は、開いているパスと保存先が一致するときだけ上書きする。書き込み上限は 10MB。ディスクの内容が開いたときと違えば SYNC-02 に進む。ブラウザ版は常にダウンロードで、パスは残らない。

### FILE-03 別名保存

**操作** ☰ の「別名保存」。⌘/Ctrl+Shift+S でも同じ。

**挙動** 保存先を選び、今の内容を書く。成功すると、そのパスが次の上書き先になる。

**制約** 拡張子は `.json`。ブラウザ版はダウンロードし、表示上のファイル名を外すので、見出しは「サンプルデータ」に戻ることがある。中身の未保存は、ダウンロードした内容と一致すれば外れる。

### FILE-04 未保存の判定

**操作** 見出しの状態を見る。

**挙動** 保存形式にした画面の JSON と、最後に開いた・保存した・読み直した JSON が違えば「未保存」になる。インデントやキー順だけの違いは、同じ内容として扱う。

**制約** 絞り込み、折りたたみ、ズーム、スクロール、系統、選択は未保存にしない。ダイアログで確定する前の入力も、未保存の判定には含めない。

### FILE-05 閉じるとき

**操作** ウィンドウまたはタブを閉じる。

**挙動** デスクトップ版で、そのパスの最後のウィンドウが未保存なら、控えを書いてから閉じる。同じパスのウィンドウが残るときは、残ったうち前面の内容で控えを書き直す。保存済みで閉じても、開いていたパスは残る。サンプルのまま未保存なら、破棄して閉じるかキャンセルするかを選ぶ。破棄して閉じると控えも消える。パスが無いウィンドウを閉じても、他のウィンドウのパスは消さない。macOS の ⌘Q を含む終了は、開いているウィンドウすべてに、同じ確認を通してからアプリを終える。確認をキャンセルしたときは、どのウィンドウも閉じない。1枚だけ閉じるときは、そのウィンドウだけを見る。ブラウザ版は、未保存のときブラウザ標準の確認になる。

**制約** 次回に戻るのはスケジュールの内容と開いていたファイルだけである。絞り込みやスクロールは戻らない。同じパスを複数のウィンドウで開いているとき、控えを書くのはそのパスを開いているウィンドウのうち前面のものだけである。前面が保存済みなら、そのパスの控えは消す。ウィンドウを1枚閉じたとき、同じパスのウィンドウが残っていれば、残ったうち前面の内容で控えを書き直す。

### FILE-06 JSON を表示

**操作** ☰ の「JSON を表示」。

**挙動** 今のスケジュールを、保存と同じ形式の JSON で見せる。ファイルには書かない。

**制約** 編集はできない。

### FILE-07 差分を表示

**操作** ☰ の「差分を表示」。未保存のときは状態バーの「未保存」。⌘ または Ctrl+Shift+D で全文をコピーする（ダイアログを開かない）。コマンドパレットの「差分をコピー」も同じ。

**挙動**

- 表示: 今の画面を保存と同じ形式にしたものと、開いているファイルをダイアログを開いた瞬間に読んだ内容との差を、選択できるテキストで見せる。「コピー」でその全文を写す。ファイルには書かない。表示は開いた時点のままで、開き直すとファイルを読み直す。
- 失敗時: パスが無いとき（サンプル、ブラウザ版）は「比べるファイルがありません」と出す。差が無いときは、見出しのあとに「差はありません」と出す。
- 対応づけ: タスク、マイルストン、カテゴリ、グループは id で対応づける。同じ id でカテゴリまたはグループの名前だけが違うときは、`変更 カテゴリ` または `変更 グループ` として `name` の前後を書く。同じ id のグループが別のカテゴリにあるときは、削除と追加にせず、`変更 グループ` の場所に移す前と移したあとの「カテゴリ名 / グループ名」を書く。名前も違うときは、場所のあとに `name` の前後を書く。親の id が同じタスクは、親の改名だけでは場所を出さない。場所の表示はカテゴリ名とグループ名のままである。同名でも id が違えば削除と追加である。別のグループへ移したタスクは、場所の変更として出す。
- 表示順: 変更と追加は画面の並び、削除はファイルの並びで書く。タスクの変わったフィールドだけを、場所、name、start、end、assigneeId、status、progress、confidence、predecessors、milestoneId、note の順で書く。タスクの変更、追加、削除では場所を必ず書く。日付の差は暦日で、`（+7日）` のように書く。先行は集合として比べ、増減だけを書く。追加は場所と全フィールドを書き、兄弟の並びは繰り返さない。削除はファイル側の名前、場所、全フィールドを書く。空のまま残っているグループとカテゴリは削除にしない。タスクを消して先行から外れたことは、残ったタスクの先行の変更として出す。カテゴリ、グループ、マイルストンの配列は、追加と削除を除いても残りの順が違うときだけ並びとして出す。タスクの並びは、同じ id の入れ替えでは左辺をファイルに残っているタスクの順、右辺を画面の順にする。末尾への追加だけなら並びは出さない。新しいタスクが末尾以外に入ったときは、右辺にそのタスクも含め、左辺はファイルに既にあるタスクの順にする。並べ替えと末尾への追加が同時のときは、右辺は末尾の追加を除いた画面の順にする。マイルストンの変わったフィールドだけを、name、date、confidence の順で書く。date の差も暦日である。

**制約** 読めない、10MB を超える、または検証に失敗したときは差分を出さず、開くときと同じ読み込みエラーを出す（コピーキーでも同じ）。絞り込み、折りたたみ、ズーム、スクロール、系統、選択、確定前の入力は含めない。未保存の表示とは別で、画面と今のファイルが同じなら未保存でも差は空である。開く、保存、別名保存の途中はボタンもキーも止める。ブラウザ版では ⌘/Ctrl+Shift+D をブラウザに渡さない。読んだ内容はこの機能のためには保存しない。スキーマは変えない。

### SYNC-01 外部更新の反映

**操作** デスクトップ版でファイルを開いたままにする。保留中は「ファイルに更新あり — 読み直す」を押す。

**挙動** 約1.5秒ごとにファイルの内容を見る。未保存でなく、ダイアログも開いておらず、詳細パネルにも入力の途中が無ければ、検証に通った内容を画面へ即時反映し、約4秒「ファイルを反映しました」と出す。未保存、または編集中なら、「読み直す」か「画面の編集を残す」かを選ぶ。読み直すと画面の編集は捨て、控えも消える。残すと見出しに「ファイルに更新あり — 読み直す」が出て、画面の内容はそのまま残る。検証に失敗した内容は反映せず、同じ内容のエラーを繰り返さない。

**制約** ブラウザ版では動かない。読み取りに5回連続で失敗すると、SYNC-03 の、ファイルが無いときのファイルダイアログを出す。1回だけの失敗では出さない。読み取り失敗の汎用メッセージは出さない。成功すると回数は戻り、同じ欠落では一度だけ出す。自分の保存は外部更新とみなさない。同じパスを別のウィンドウで開いているとき、片方が保存すると、もう一方は外部更新として扱う。保存した側は、自分の保存を外部更新にしない。

### WIN-02 他ウィンドウのファイル更新の知らせ

**操作** デスクトップ版で、同じファイルを複数のウィンドウで開く。片方で SYNC-01 の反映または確認が終わる。

**挙動** 結果を他のウィンドウへ知らせる。知らせを受けたウィンドウの隅に、ファイル名と「反映した」か「確認待ち」を出す。押すと、更新が起きたウィンドウを前面に出す。「反映した」は数秒で消す。「確認待ち」は、そのウィンドウが確認を終えるまで残る。確認が終わると「確認待ち」は消え、読み直したときは「反映した」に替わる。未保存のウィンドウは、知らせだけでは書き換えない。アプリのどのウィンドウも前面に無いときだけ、同じ内容を OS の通知で1回出す。通知のクリックを受け取れる環境では、押すとそのウィンドウを前面にする。

**制約** ブラウザ版では動かない。通知が出せない環境でも、アプリ内の知らせは動く。

### SYNC-02 保存時の外部更新の確認

**操作** 外部で変わったファイルに対して「保存」を押す。

**挙動** 「上書き保存」「別名保存」「取り消し」を選ぶ。上書きはそのパスへ書く。別名保存は別のパスを選ぶ。取り消しは何も書かない。

**制約** 開いたあと一度も外部の変化を見ていなくても、保存の直前にディスクと比べる。

### SYNC-03 前回のファイル

**操作** デスクトップ版でファイルを開き、保存して、または未保存のまま閉じて、次に起動する。

**挙動** 開いていたウィンドウを `open-windows.json` に順に書く。各要素はウィンドウのラベル、パス、またはパスの無いサンプルである。前面にあったウィンドウのラベルも書く。未保存の控えはパスごとに1ファイル。`schedule-recovery/` に、パスのハッシュを名前にした JSON を置く。中身は `path`、`baselineJson`、`documentJson` である。サンプルは控えを作らない。次回起動時、記録にあるウィンドウをそれぞれ作る。同じパスが複数あるときは1つにし、閉じる時点で前面だったウィンドウの未保存だけを残す。`open-windows.json` が無く、古い `last-schedule.json` がある初回起動は、その1枚として開く。古い控えがあれば、そのパスの控えへ移し、移し終えたら古い2ファイルは消す。

各ウィンドウについて、ファイルがあり、未保存が無いか、ディスクが控えの基準と一致すれば、そのファイルを開く。未保存があれば、その内容を未保存のまま戻す。警告は出さない。ディスクが未保存の内容と違えば、「ファイルを開く」か「未保存の編集を戻す」かを選ぶ。開くならそのパスの最新内容を保存済みとして読み、控えは消す。戻すなら画面は控えのままで、ディスクの内容はあとから読み直せる。

前回のファイルが無く、未保存も無いときは、見つからないことを知らせてサンプルにする。ファイルダイアログは出さない。前回のファイルが無く、未保存があるときは、未保存を画面に戻し、ファイルが無いことを知らせる。「未保存の編集を戻す」はその内容を残す。「ファイルを開く」は、下のファイルダイアログである。この起動でファイルが無いと知らせたあとは、そのファイルが再び読めるまで、監視のファイルダイアログは出さない。

ファイルが無いときの「ファイルを開く」は、起動時の警告と、作業中にファイルが消えたときで同じである。覚えたパスは直接開かず、OS のファイルダイアログを出す。初期フォルダは、保存先の親フォルダが残っていればそこ、無ければホームである。消えたファイルは初期選択にしない。キャンセルすると、画面に出している内容と見出しのパスを残す。未保存なら、破棄して開くかの確認を先に出す。選んだあとは、通常の開くと同じ検証に進む。作業中は、1回読めないだけでは出さず、5回連続で読めなくなってから出す。

**制約** 戻るのはスケジュールの内容と開いていたファイルだけである。絞り込み、折りたたみ、ズーム、スクロール、系統、選択は戻らない。サンプルではパスも控えも作らない。保存、破棄して別ファイルを開く、外部の内容を読み直したときは控えを消す。「画面の編集を残す」では消さない。ブラウザ版ではパスも控えも残さない。上書き保存は、ファイルが無いパスへは書けない。別名保存は書ける。控えが壊れている、またはファイルはあるが検証できないときは、その旨を出してサンプルのままにする。記録は残し、「控えを破棄」で控えを消せる。破棄するまで起動のたびに知らせる。開いているウィンドウがサンプルだけになったとき、次回はサンプルから始まる。前回のファイルを開き終わるまでは、画面のスケジュールを変更できない。取り消しとやり直しも受け付けない。開き終わったあとは変更できる。開き終わるまでにファイルが変わっていれば、開いたあと SYNC-01 と同じように読み直す。開いているあいだの編集や、外からの書き換えは止めない。2つ目のアプリを起動したときは、既存のアプリを前面に出し、新しいプロセスは起動しない。

### VIEW-01 階層

**操作** 画面を見る。

**挙動** 行はカテゴリ、グループ、タスクの3段で、JSON の配列順に並ぶ。絞り込みも系統も無いときは、タスク0件のグループと、配下のタスクがすべて0件のカテゴリも行に出す。絞り込み中と系統の表示中は、条件に合うタスクが無い行は出さない。データとしては残る。

**制約** タスクの並びと別グループへの移動は EDIT-15、グループの並びと別カテゴリへの移動は EDIT-17、カテゴリの並びは EDIT-16 で変えられる。

### VIEW-02 タスクバー

**操作** タイムラインのタスク行を見る。

**挙動** バーは開始日から終了日の終わりまでを塗る。終了日はその日を含む。未着手は灰、進行中は薄青に進捗率の濃い部分、完了は緑である。選択中は枠を太くする。バーが十分に長いときは、バーの中に名前と進捗率を出す。短いときや月表示では、バーの右に名前と担当を出す。

**制約** 進捗の塗りは進行中だけに出す。幅は1日より短くならない。

### VIEW-03 親バー

**操作** カテゴリ行とグループ行を見る。

**挙動** 見えている子のうち、最も早い開始日から最も遅い終了日までのバーを、タスクバーより細い帯で出す。両端に下向きの小さな角を付ける。子が途切れている期間は点線、つながっている期間は塗りで示す。折りたたんでも親バーは残る。縦スクロールで残している行の親バーも横スクロールに追従し、ドラッグできないままである。タスクが無いグループとカテゴリには親バーを出さない。行には名前だけ出す。HTML と SVG の書き出しも同じ形である。

**制約** 親バーはドラッグできない。

### VIEW-04 マイルストン帯

**操作** 日付ヘッダーの下を見る。

**挙動** `milestoneGroups` の配列順に、グループごとに帯を積む。各グループの中では、マイルストンをひし形と名前で置く。確定のひし形は塗りつぶす。未確定のひし形は、同じ色の地に斜線を重ねる。同じグループでひし形が重なるときだけ段を増やす。名前の長さでは段を増やさない。名前は同じ段の次のひし形の手前まで出す。空きがあれば全文を出す。カーソルを乗せているあいだは、その位置に全文を重ねる。段は横スクロールでは変わらない。日・週・月の切り替えで1日の幅が変わると、重なりが変わり、段も変わる。チャート全体へ縦線は引かない。マイルストンが無ければ帯の高さは 0 である。空のグループは線を出さない。

**制約** 左には、見えているグループごとに、そのグループ名と段の高さに合わせた行を出す。

### VIEW-05 期限超過

**操作** 今日より前に終わる未完了タスクを見る。

**挙動** バーを赤くし、左のタスク名も期限超過の見た目にする。終了日が今日のタスクは超過にしない。完了は終了日が過去でも超過にしない。

**制約** 進捗率では判定しない。

### VIEW-06 マイルストン超過

**操作** 対応マイルストンよりあとまで延びたタスクを見る。

**挙動** マイルストンの日付より右を、タスクバーの赤い枠で囲み、行に「超過」を出す。終了日がマイルストン当日なら超過にしない。対応が未設定なら判定しない。HTML と SVG の書き出しも同じ枠である。

**制約** 期限超過とは別である。両方あり得る。

### VIEW-07 イナズマ線

**操作** チャート上の本日の線を見る。

**挙動** 基準はパソコンの今日の日付で、日付が変わると更新する。行の中央で折れる。期限超過の行では終了日まで左へ、着手済みで開始日が今日より後の行では開始日まで右へ、それ以外は今日の位置に置く。色は橙色で、太さ 1.5px、不透明度 0.55 である。設定で非表示にできる。HTML と SVG の書き出しも同じ太さと不透明度を使い、非表示のときは線を出さない。

**制約** 進捗率は見ない。未着手で開始日が未来でも、今日の位置のままである。

### VIEW-08 前後の線

**操作** 先行と後続が両方見えているタスクを見る。

**挙動** 先行から後続へ矢印を引く。間隔があるときは先行の右端から右へ出て縦に折れ、後続の左端へ入る。終了と開始が近く、右へ出る余地が矢印の頭より狭いときは、先行バーの外側を回ってから、後続の左端の手前で右を向いて入る。頭は後続バーの外に残る。後続の開始が先行の終了より前なら赤く太くする。同じ日に始まる線は赤くしない。フィルタや折りたたみでどちらかが見えなければ線は出さない。線を引くモードの追随する線は、確定した矢印ではない。バーの移動または端のドラッグのあいだは、そのタスクが端になる線だけ、離したときに入る日付で色を追従させ、線はそのバーの見た目の位置に付いてくる。他のタスクの線の色と位置は変えない。絞り込みで見えている行は、離して確定するまで変えない。

**制約** 「前後: 破綻のみ」のときは、破綻している線だけを描く。追随する線は破綻の赤にしない。

### VIEW-09 非稼働日

**操作** 日表示または週表示の背景を見る。

**挙動** 非稼働日を薄い灰色で塗る。カレンダー未設定なら土日、設定済みなら [データ仕様](data-format.md#稼働日カレンダー-jsonschemaversion-1) の判定に従う。HTML と SVG の書き出しも同じである。

**制約** 月表示では日ごとに塗らない。バーの移動と期間は暦日のままである。

### VIEW-10 担当の表示

**操作** タスク行の右側を見る。

**挙動** 左の一覧では、解決できたメンバーは表示名を出す。同じ表示名が複数あるときだけ ID を添える。割り当てなしは担当欄に「未割当」と薄く出す。メンバー不明は「メンバー不明」と ID を出す。チャートのバーでは担当はバーの右の文字で示し、割り当てなしの破線や上端の色は出さない。期限超過の赤は、一覧の表示より優先する。

**制約** 使用中カタログが無いとき、ID がある担当はすべてメンバー不明になる。

### VIEW-11 ノートアイコン

**操作** タスク行の左のノートアイコンを見る。

**挙動** ノートがあるタスクと無いタスクで色を分ける。押すとノートの全文をダイアログで開く。行の選択は変わらない。空のときは「ノートはありません」と出す。

**制約** ノート本文は行に常時出さない。

### VIEW-12 確度

**操作** タスクのバーと、左のタスク行と、マイルストンのひし形を見る。

**挙動** 確定のバーはベタ塗りである。未確定のバーは、同じステータス色の地に斜線を重ねる。斜線は、ライトでは地より濃く、ダークでは地より明るく、地の色が残る間隔である。左の一覧では「未確定」は出さない。マイルストンの「超過」があるときは一覧に「超過」を出す。確定のマイルストンはひし形を塗りつぶす。未確定のマイルストンは、同じ色の地に同じ斜線を重ねる。HTML と SVG の書き出しも、同じ斜線を出す。

**制約** 枠の線種、上端の色、進捗の濃い帯、期限超過の赤は変えない。進捗の濃い帯は斜線の上にベタで描く。親バーと前後の線は、タスクの確度では変えない。マイルストンのひし形は、そのマイルストン自身の確度で変える。確度は着手や進捗とは独立である。

### NAV-01 スクロール

**操作** チャートをドラッグする。チャート本体か左の一覧の上で、ホイール、または Shift+ホイールを回す。⌘ または Ctrl を押しながら矢印キーを押す。

**挙動** 修飾キーを押さないドラッグは、縦横にスクロールする。チャート本体と左の一覧の上では、ホイールで縦、Shift+ホイールで横に動く。左の一覧の上で Ctrl または ⌘ とホイールを回すと、チャートの左端の日付を保って NAV-02 と同じ倍率になる。日付ヘッダーとマイルストン帯の上では、ホイールで横に動く。⌘ または Ctrl と矢印では、上で縦に戻り、下で縦に進む。左で日付を過去へ、右で未来へ動かす。縦は左の一覧とチャートが一緒に動く。上下は 1 行分、左右はその行と同じ画面上の距離だけ動く。キーを押しているあいだは連続して動く。端では止まる。右クリックメニューが開いていれば閉じる。日付ヘッダーとマイルストン帯は、その上に固定されたままである。縦にスクロールしたとき、展開していて配下がまだ下に残っているカテゴリ行とグループ行は、その下に最大2行残る。残すのはカテゴリ1行とグループ1行で、表示サイズで行の高さが変わっても同じである。左の名前と右の親バーは一緒に残る。見た目は通常のカテゴリ行・グループ行のままで、固定用の装飾は足さない。同じ行は二重に出さない。一覧が画面に収まるときは残さない。固定段はタスクに重ならない。折りたたんだカテゴリとグループは残さない。その行自身は通常どおり上へ流れる。絞り込みと系統で省いた行は対象にしない。次の見出しが上端へ来るときは入れ替わる。前後の線、イナズマ線、残していない行のバーは固定段の下で切れ、固定段の上には描かない。固定段の上の操作はそのカテゴリ行またはグループ行に当たる。折りたたみ、右クリックの「名前を変更」、切れた名前の全文は、固定中の行にマウスを乗せても出る。カテゴリ行の並べ替えは、固定中の行の握りからも始められる。グループ行の並べ替えも、固定中の行の握りから始められる。追加や複製でタスクを見える位置へ寄せるときは、固定段の下にタスクが出る位置までスクロールする。デスクトップ版とブラウザ版で同じである。

**制約** タスクバーの上では、修飾キーの無いドラッグは移動か期間変更になる。空いた所、スペースキーを押したドラッグ、中ボタンのドラッグはスクロールのままである。スペースキー単体は、フォーカスが `body` かチャート本体にあるときだけスクロール用に取り、ボタンにフォーカスがあるときはボタンの既定の動作に渡す。移動と期間変更は 8px を超えてから始まり、離す前の Escape で取り消せる。Escape ではドラッグを止めて形を戻し、離したときの確定や取り消し履歴には積まない。3px 未満の動きはスクロールとみなさない。修飾キーの無い ↑↓ はタスクの選択を移し、Alt+←→ は開始日と終了日を、Shift+Alt+←→ は終了日だけを 1 日ずらす。検索欄、入力欄、選択欄、ボタン、ダイアログではこれらの矢印はその欄の操作のままである。それ以外の修飾キーの無い矢印キーではチャートを動かさない。Shift または Alt を一緒に押しているときは、矢印では動かさない。検索欄、選択欄、ボタンにフォーカスがあっても、⌘ または Ctrl と矢印はチャートを動かす。ダイアログが開いているあいだは動かない。Mac では Ctrl+矢印が OS に取られて届かないことがある。届いた ⌘ または Ctrl は同じ動きにする。スケジュールのデータ、取り消し履歴、選択、絞り込みは変わらない。ドラッグ、ホイール、Shift+ホイールの動きは変えない。線を引くモードのあいだは、チャート上のドラッグでスクロールも移動も期間変更もマイルストンの日付変更もしない。ホイール、Shift+ホイール、⌘ または Ctrl と矢印は、モード中もスクロールする。

### NAV-02 ズームと日・週・月の切り替え

**操作** チャート本体か左の一覧の上で、Ctrl または ⌘ を押しながらホイールを回す。ツールバーの「日」「週」「月」を押す。「今日」を押す。

**挙動** ホイールは、マウスポインタの位置を基準に、1日あたりの幅を約1.15倍ずつ変える。左の一覧の上では、チャートの左端の日付を保つ。「日」は 40px、「週」は 22px、「月」は 8px に幅を決め、チャートの中央を基準に変える。幅に応じて見出しの表示単位は、40px 以上なら日表示、10px 以上 40px 未満なら週表示、それ未満なら月表示になる。「今日」は、縦位置と選択は変えず、横スクロールだけを今日の日付が見える位置へ寄せる。今日が期間の外なら、端で止める。

**制約** 幅は 3px 以上 90px 以下。既定は 22px で週表示になる。このズームは、設定の表示サイズとは別である。

### NAV-03 Fit

**操作** 「全体」を押す。ファイルを開いた直後も同じ処理が走る。

**挙動** 表示中の全期間がチャート幅に入るよう1日あたりの幅を決め、横位置を先頭に戻す。

**制約** 幅の上下限は NAV-02 と同じである。下限に当たると、全期間が入り切らないことがある。

### NAV-07 コマンドパレット

**操作** ⌘ または Ctrl と K を押す。欄に文字を入れて候補を絞り、↑↓ で選び、Enter で実行する。

**挙動** 開く、保存、別名保存、検索へ移る、差分を表示、差分をコピー、JSON を表示、書き出し、設定、ショートカット一覧、今日、日・週・月・全体、取り消し、やり直し、表示サイズの拡大と縮小、選択中タスクの編集、削除、線を引く、ノート、系統を候補に出す。ファイル操作の途中や、選択が無い操作は、候補を残したまま押せない。同じ ⌘/Ctrl+K と Escape で閉じる。

**制約** ほかのダイアログが開いているあいだは開かない。検索欄や入力欄にフォーカスがあっても開ける。コマンドパレットの中では、キー操作はパレットが受け取り、ほかのショートカットは効かない。

### NAV-04 折りたたみ

**操作** カテゴリまたはグループの左の三角を押す。

**挙動** 配下の行を隠す。もう一度押すと戻す。畳んでもその行と親バーは残る。追加したタスクのカテゴリとグループは、追加時に展開する。

**制約** 折りたたみは取り消し履歴に入らない。ファイルを開くとすべて展開に戻る。

### NAV-05 切れた名前

**操作** 左の名前が幅に収まらないとき、その名前にマウスを乗せる。

**挙動** 全文が出る。名前をドラッグしても、名前は動かない。データは変わらない。

**制約** 収まっている名前には全文を出さない。担当、追加列、「超過」は動かない。

### NAV-06 左一覧の幅

**操作** 左の一覧とチャートの境界を横にドラッグする。境界をダブルクリックするか、境界にフォーカスして左右キーを押しても変えられる。⌘ または Ctrl を押した左右キーでは変えない。

**挙動** 一覧の幅が変わり、チャートは残った幅に合わせて縮む。幅は表示倍率に比例し、表示倍率 1 のときの既定は 260px である。離した幅は localStorage に残り、次の起動でも使う。ダブルクリックは既定に戻し、保存した幅を消す。左右キーは、見えている幅を基準に、基準幅を 8 ずつ動かす。⌘ または Ctrl が付いているときは幅を変えず、NAV-01 のとおり横にスクロールする。そこに Shift または Alt も一緒のときは、幅もスクロールも変えない。ドラッグも左右キーも、表示幅が変わらないときは覚えている幅を変えない。ウィンドウを狭めてチャートが 200px を下回りそうなときは、その場の表示だけ縮め、覚えている幅は残す。広げ直すと、その幅に戻る。

**制約** 利用者が指定する基準幅は 140 未満にしない。チャート側は 200px 未満にしない。スケジュールのデータと取り消し履歴は変わらない。切れた名前の全文は、名前にマウスを乗せたときに出る。書き出しのラベル幅は、画面の一覧幅とは別に、名前が収まる長さで決める。

### FILTER-01 タスク名

**操作** 検索欄の対象を「名前」にし、文字を入れる。⌘/Ctrl+F で検索欄へ移し、入っている文字を選択する。対象が「名前」のときだけ、⌘/Ctrl+F は名前の欄へ移る。

**挙動** 名前にその文字を含むタスクだけを残す。前後の空白は除いて比べる。

**制約** 大文字小文字は区別する。絞り込みを変えると選択は外れる。

### FILTER-02 ノート

**操作** 検索欄の対象を「ノート」にし、文字を入れる。

**挙動** ノートにその文字を含むタスクだけを残す。ノートが無いタスク、空白だけのノートは残さない。タスク名の検索と併用したときは、両方を満たすタスクだけが残る。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-03 担当者

**操作** 「絞り込み」パネルの「担当者」で「すべて」「割り当てなし」、またはメンバーを選ぶ。

**挙動** 「割り当てなし」は、割り当てなしとメンバー不明の両方を残す。特定のメンバーは、その ID のタスクだけを残し、メンバー不明は出さない。カタログが変わり、選んでいた ID が消えると「すべて」に戻る。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-04 ステータス

**操作** 「絞り込み」パネルの「ステータス」で「すべて」「完了以外」「未着手」「進行中」「完了」を選ぶ。

**挙動** 「完了以外」は `done` 以外を残す。ほかは、そのステータスだけを残す。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-05 期限

**操作** 「絞り込み」パネルの「期限」で「すべて」か「期限超過」を選ぶ。

**挙動** 「期限超過」は VIEW-05 のタスクだけを残す。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-06 前後

**操作** 「絞り込み」パネルの「前後」で「すべて」か「破綻のみ」を選ぶ。

**挙動** 「前後: 破綻のみ」は、破綻している線の両端のタスクだけを残す。線の見た目は VIEW-08 に従う。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-07 マイルストン

**操作** 「絞り込み」パネルの「マイルストン」で「すべて」「なし」、またはマイルストンを選ぶ。

**挙動** 「なし」は対応マイルストンが無いタスクだけを残す。特定のマイルストンは、それを指すタスクだけを残す。選んでいたマイルストンが消えると「すべて」に戻る。

**制約** 絞り込みを変えると選択は外れる。

### FILTER-11 マイルストン帯の線

**操作** 「絞り込み」パネルの「帯の線」で、マイルストングループごとに表示のオンオフを切り替える。

**挙動** オフにしたグループの線は、帯と書き出しの両方から消える。書き出しの期間の端にも、そのグループの日付は使わない。タスク一覧の絞り込み（FILTER-07）と、タスク行の超過は変えない。初期は全部オンである。消えたグループの選択は捨て、新しいグループはオンである。「すべて解除」では、帯の線も全部オンに戻す。系統は外さない。

**制約** 取り消し履歴には入らない。1つでもオフがあれば、絞り込みの条件数に数える。

### FILTER-08 系統

**操作** タスクを選んで「系統」を押す。もう一度押すと解除する。右クリックメニューの「系統を表示」は、そのタスクを起点にする。すでにそのタスクが起点なら「系統を解除」になる。

**挙動** 起点から先行と後続をたどれるところまでたどり、そのタスクだけを残す。起点を通らない枝は含めない。ボタンには起点の名前を出す。効いているときは、絞り込みの札にも「系統: 名前」を出し、札を押すと解除する。別のタスクが起点のときに「系統を表示」を選ぶと、起点をそのタスクへ切り替える。ツールバーの「系統」は、起点があるあいだは解除だけをする。タスクを追加したとき、または起点のタスクを削除したときは解除する。

**制約** タスクを選んでいないときは押せない。絞り込みを変えても系統自体は外れないが、選択は外れる。系統は取り消し履歴に入らない。

### FILTER-09 組み合わせと空のグループの省略

**操作** 複数の絞り込みと折りたたみ、系統を同時に使う。

**挙動** タスクはすべての条件を満たすものだけが残る。絞り込みも系統も無いとき以外は、残ったタスクが無いグループとカテゴリは行から省く。折りたたみは、残った行をさらに隠す。前後の線は、両端が行として見えているときだけ描く。

**制約** 省いたグループとカテゴリはデータに残り、追加ダイアログでは選べる。絞り込みも系統も無いときは、空のグループとカテゴリも行に出す。

### FILTER-10 確度

**操作** 「絞り込み」パネルの「確度」で「すべて」「未確定」「確定」を選ぶ。

**挙動** 「未確定」は `tentative` だけを残す。「確定」は `committed` だけを残す。

**制約** 絞り込みを変えると選択は外れる。ステータスや進捗では判定しない。

### EDIT-01 選択

**操作** タスクバーまたは左のタスク行の握り以外をクリックする。背景を左クリックすると解除する。タスク行の握り以外、またはバーを右クリックすると、そのタスクを選択する。↑↓ で見えているタスクの前後へ選択を移す。

**挙動** 選択したバーに期間変更のハンドルを出す。詳細パネルが開く。「削除」が押せるようになる。追加に成功すると、そのタスクを選択し、固定段の下に出る位置までスクロールする。↑↓ で選択を移すとき、行が縦に画面外なら入るところまでだけスクロールする。見えている行を選んでも縦位置は変えない。バーが横の表示範囲にすでにかかっているときは、横スクロールは変えない。かかっていないときだけ、開始日の少し手前が見える位置へ寄せる。カーソルを乗せたタスク行は、一覧とチャートで薄い帯を出す。

**制約** 並べ替えの握りはドラッグ専用である。クリック、右クリック、3px 以内で離した操作では選択を変えず、詳細パネルやメニューを開かない。並べ替えになったドラッグでも選択を変えない。絞り込みの変更、削除、別ファイルを開くと選択は外れる。スクロールと判定したドラッグでは選択を変えない。バー端の期間ドラッグの当たりでは選択しない。

### EDIT-02 移動

**操作** タスクバーの本体を横にドラッグし、離す。⌘ または Ctrl を押したドラッグでも同じ。

**挙動** 開始日と終了日を、ドラッグした日数だけ動かす。縦には動かない。他のバーと日付の位置は動かない。ドラッグを始めたときから離すまで、開始日と終了日を両方、`4/3` のように月と日だけで出す。年と曜日は出さない。数字は、離したときに入る日に合わせる。文字の大きさは、チャートのズームではなく画面の表示倍率に従う。文字は不透明な地の上に書き、チャートの背景が文字に透けないようにする。地は、動かしている棒、もう一方の日付の地、見えている他の棒には重ねない。空いているときは各端の上に置き、重なるときや画面の端では、棒の外側へずらして画面内に収める。離すと日付は消える。離したときに1回だけ確定し、取り消しの1ステップになる。

**制約** バーの端のドラッグと、空いた所のドラッグでは日付は出さない。期間の長さは変わらない。確度は変わらない。左の名前、マイルストンのひし形、親バーには出さない。開始日や終了日が非稼働日でも印は出さない。バーの長さは暦日のままである。

### EDIT-03 期間変更

**操作** バーの左端または右端を横にドラッグし、離す。選択前でも端をドラッグできる。端とその周りの当たりは、期間を変えるドラッグだけを受ける。

**挙動** 左端は開始日、右端は終了日を変える。ドラッグ中は、開始日と終了日の両方を EDIT-02 と同じ置き方で出す。1日より短くならない位置で止まった日付を出す。離したときに1回だけ確定する。離しても選択は変わらない。Escape の取り消しは EDIT-02 と同じである。

**制約** 期間は1日未満にできない。終了日は開始日より前にできない。確度は変わらない。バー本体の移動と、空いた所のドラッグでは日付を出さない。端の当たりのクリック、ダブルクリック、右クリックでは、選択も詳細パネルもメニューも変えない。バーの移動とパンも始まらない。当たりはバーの外へ 12px、バーの中へは最大 16px で、上下はバーの高さである。バーが長いときは中央に 8px のクリックできる幅を残す。それより短いバーは端の当たりが重なる。

### EDIT-04 詳細パネル

**操作** タスクを選ぶ。バーの本体をダブルクリックする。選択中に Enter を押すか、右クリックメニューの「編集」でも、詳細パネルの名前欄にフォーカスを移す。端の当たりのダブルクリックでは移さない。

**挙動** 右に幅 320px（表示倍率に比例）のパネルが出る。背面は暗くせず、チャートと一覧は操作できる。名前とノート、期間、担当・ステータス・進捗・確度、マイルストンと前後関係を編集できる。項目を確定するとスケジュールに反映し、取り消しの1ステップになる。同じ内容は積まない。

**制約** タスク名は必須。日付は実在する日で、終了日は開始日以降。進捗率は 0 以上 100 以下の整数。循環する前後関係や、存在しない先行は保存せず、理由を出す。パネルの入力欄にフォーカスがあるあいだは、外部ファイルの即時反映を止める。

### EDIT-05 前後関係

**操作** 詳細パネルの先行と後続でタスクを足す、または外す。

**挙動** 先行に足したタスクの ID は、自分の `predecessors` に入る。後続に足すと、相手の `predecessors` に自分の ID が入る。候補は名前で絞れ、自分自身は出さない。先行にいるタスクは後続の候補から外し、後続にいるタスクは先行の候補から外す。選択済みは、カテゴリとグループを1行、タスク名を次の行に出す。長い階層はカテゴリとグループの行だけを省略する。ホバーでは「カテゴリ / グループ / タスク名」の全文が出る。見つからない ID は `ID` と ID の1行で、ホバーも同じ文字列である。

**制約** 候補は一度に50件までである。それを超えると「さらに絞り込んでください」と出す。

### EDIT-06 ノート

**操作** ノートアイコン、右クリックメニューの「ノート」、または選択中のタスクで ⌘/Ctrl+N からノートダイアログを開く。詳細パネルのノート欄からも保存する。

**挙動** 書いた内容をタスクの `note` にする。空白だけを保存するとプロパティを消す。確定すると取り消しの1ステップになる。⌘/Ctrl+N では、選択中のタスクのダイアログが開く。タイトルはタスク名で、ノート欄にフォーカスする。ノートが無い、または空白だけなら「ノートはありません」と出す。選択は変えない。右クリックメニューが開いていれば閉じる。キーのリピートでは開かない。

**制約** 空のノートは JSON に書かない。タスクが選択されていないときは開かない。マイルストンにはノートが無く、このキーの対象ではない。ダイアログが開いているあいだと、線を引くモードのあいだは開かない。検索欄、入力欄、選択欄では効かない。ボタンにフォーカスがあっても効く。N だけ、Shift や Alt が一緒のときは開かない。Shift 付きはアプリが取らない。ブラウザ版では、開くときも、選択が無いなどで何もしないときも、⌘/Ctrl+N はブラウザに渡さない。スキーマは変えない。

### EDIT-07 マイルストン

**操作** 「マイルストン追加」で名前、日付、確度を指定して足す。日付ヘッダー、マイルストン帯の空き、チャート本体の空きを右クリックし、「マイルストンを追加」を選んでも、同じダイアログが開く。マイルストンが 0 件で帯が無いときでも、ツールバーと、日付ヘッダーとチャート本体の空きから足せる。ひし形、またはその右の名前を横にドラッグする。同じ場所のダブルクリック、または右クリックメニューの「編集」で名前、日付、確度を編集する。右クリックメニューの「削除」で確認して消す。

**挙動**

- 追加: 名前の初期値は空、確度の初期値は未確定である。ツールバーから開いたときの日付の初期値は画面の今日である。日付ヘッダー、マイルストン帯の空き、チャート本体の空きから開いたときは、ポインタの横位置が含まれる暦日である。その日の左端から、次の日の左端の手前までがその日である。月表示でヘッダーが月のラベルでも、日で決める。配列の末尾に1件足す。入れる先は `milestoneGroups` の先頭である。グループが無いときは、名前「マイルストン」のグループを1つ作って入れる。同じ名前と日付でも足せる。保存する名前は前後の空白を除いたものである。ID は、そのスケジュールのカテゴリ、グループ、タスク、マイルストン、マイルストングループの ID のどれとも重ならない UUID である。追加しても絞り込み、折りたたみ、ズーム、スクロール、系統、選択は変えない。足した日付が今の範囲の外なら、保存後の期間は、全タスクと全マイルストンから今までどおり決まる。
- 表示順: 日付順には並べ替えない。
- ドラッグ: 日付を日単位で変え、離したときに確定する。確度は変えない。
- 編集: 名前、日付、確度を変える。日付が空なら保存しない。名前が空白だけなら、元の名前を残す。
- 削除: マイルストンを配列から外し、その ID を指すタスクの `milestoneId` をすべて外す。タスクの日付、先行、ステータス、進捗、ノートは変えない。空のグループとカテゴリは残す。見えていないタスクも含め、その ID を指すタスクが1件でもあれば、確認に「このマイルストンを指しているタスクの対応は外れます。タスクの日付は変えません。」を出す。無ければその文は出さない。絞り込んでいたマイルストンを消したときだけ、マイルストンの絞り込みを「すべて」に戻す。「なし」と「すべて」と別のマイルストンはそのままである。選択と系統と折りたたみは変えない。
- 履歴: 追加と削除は、それぞれ取り消しの1ステップである。絞り込みを「すべて」に戻すことは履歴に入らない。取り消しても絞り込みは「すべて」のままである。

**制約** 名前が空白だけなら「名前を入力してください」、日付が空または実在しない日なら「日付を入力してください」と出し、追加しない。ダイアログは開いたままにする。キャンセルと Escape では足さない。ツールバーの「追加」と「削除」、Delete、Backspace はタスクのままである。確認をキャンセルすると消さない。当たりは、ひし形の円と、名前の文字の矩形と、そのあいだの隙間である。名前の幅は段の割り当てに使う幅と同じで、右端より右は当たらない。上下は円の直径と文字の高さのうち広い方で、段の上下の空きと段の高さ全体には広げない。名前が空のときは円だけである。左のグループ名の行は当たらない。線を引くモードでは、名前の上でも編集もドラッグもメニューも出さない。ホイールの横スクロールは変えない。

### EDIT-08 追加

**操作** 「追加」を押し、カテゴリ、グループ、タスク名、開始日、終了日を指定する。

**挙動** 選んだグループの末尾にタスクを足す。選択中のタスクがあれば、そのカテゴリ、グループ、日付を初期値にする。無ければ先頭のカテゴリとグループ、今日の日付を使う。新しいタスクは割り当てなし、未着手、進捗 0、未確定、前後関係なし、対応マイルストン未設定で、ID は、カテゴリ、グループ、タスク、マイルストンの ID と重ならない新しい UUID である。追加後はその行が見えるよう展開し、系統を解除し、そのタスクを選択する。

絞り込みは、新しいタスクを隠してしまうものだけを外す。

- 担当者: 特定のメンバーなら「すべて」に戻す。「割り当てなし」はそのまま残す
- ステータス: 「完了」か「進行中」なら「すべて」に戻す。「完了以外」と「未着手」はそのまま残す
- 確度: 「確定」なら「すべて」に戻す。「未確定」と「すべて」はそのまま残す
- 期限: 「期限超過」で、新しいタスクが期限超過でなければ「すべて」に戻す
- 前後: 「前後: 破綻のみ」は外す
- マイルストン: 特定のマイルストンなら「すべて」に戻す。「なし」はそのまま残す
- タスク名の検索: 新しい名前に含まれない文字なら消す
- ノートの検索: 文字が入っていれば消す

**制約** 終了日が開始日より前なら追加しない。期間は1日未満にできない。空のグループとカテゴリも追加先として選べる。

### EDIT-09 削除

**操作** タスクを選んで「削除」を押すか、Delete または Backspace を押し、確認する。右クリックメニューの「削除」でも同じ確認を開く。

**挙動** そのタスクを消す。他のタスクの先行からはその ID を外し、前後のタスク同士はつながない。系統の起点を消したときは系統を解除する。空になったグループとカテゴリはデータに残す。線の上で Delete または Backspace を押したときは、タスクは消さず、EDIT-12 のとおりその線だけを外す。

**制約** タスクを選んでいないと「削除」は押せない。確認をキャンセルすると消さない。検索欄、入力欄、選択欄、ボタンにフォーカスがあるときは、Delete と Backspace では消さない。ツールバーの「削除」は、線の上でもタスクを消す。

### EDIT-10 取り消し・やり直し

**操作** ⌘/Ctrl+Z で取り消す。⌘/Ctrl+Shift+Z、または Ctrl+Y でやり直す。

**挙動** カテゴリ、グループ、タスク、マイルストンの確定した変更を1操作1ステップで戻す。対象はバーの移動、期間変更、マイルストンの移動、詳細パネルでの項目の確定、ノートの保存、確度の切り替え、カテゴリとグループの改名、カテゴリとグループの追加と削除、タスクの複製、タスクの削除、タスクの並べ替えと別グループへの移動、グループの並べ替えと別カテゴリへの移動、カテゴリの並べ替え、チャート上で線を足すこと、線を1本外すことである。最大100件まで覚える。ファイルを開くと履歴は空になる。

**制約** タイトル、絞り込み、折りたたみ、ズーム、スクロール、系統、選択は履歴に入らない。ダイアログ、検索欄、入力欄にフォーカスがあるときは、取り消し・やり直しのキーはスケジュールに効かない。同じ内容の変更はステップに積まない。

### EDIT-11 右クリックメニュー

**操作** タスクのバー、または左のタスク行を右クリックする。マイルストンはひし形、またはその右の名前を右クリックする。左のカテゴリ行とグループ行も右クリックする。日付ヘッダー、マイルストン帯の空き、チャート本体の空きも右クリックする。

**挙動** メニューは、ポインタの下にあるものの操作だけを出す。重なったときは上から先に当たる 1 つだけである。タスクでは「編集」、「複製」、確度、ノート、系統、削除のあいだに区切りを入れる。「編集」の右に Enter、「ノート」の右に ⌘N または Ctrl+N、「削除」の右に Delete を出す。削除の文字は危険色である。各項目の左に小さなアイコンを置く。マイルストン、カテゴリ、グループでも、削除の前に区切りを入れ、削除の文字は同じ危険色である。確度の切り替えは日付を動かさず、取り消しの1ステップである。右クリックしたタスクを選択する。マイルストンでは「編集」、今の確度と逆の「確定にする」または「未確定にする」、「削除」を出す。確度の切り替えは日付を動かさず、取り消しの1ステップである。右クリックしても選択しない。左のカテゴリ行では「名前を変更」、「下にカテゴリを追加」、「グループを追加」を出し、消せるときだけ「削除」を足す。左のグループ行では「名前を変更」、「下にグループを追加」を出し、消せるときだけ「削除」を足す。名前の変更と追加は EDIT-13 または EDIT-18 のダイアログを開く。削除は EDIT-19 の確認を開く。見えている線の上では「線を外す」だけを出す。日付ヘッダー、マイルストン帯の空き、チャート本体の空きでは「マイルストンを追加」だけを出す。選ぶと EDIT-07 の追加ダイアログが開く。右クリックでは選択を外さない。チャートの空きの左クリックで選択を外すのは今どおりである。メニューはクリック位置に出し、画面の端では内側へずらす。項目を選ぶ、外側をクリックする、Escape、スクロール（⌘/Ctrl+矢印を含む）、表示サイズの変更（SET-01）、またはダイアログが開くと閉じる。選択中バーの端の当たりではメニューを出さない。バー本体では同じメニューが出る。タスクの削除は確認を開く。カテゴリとグループの削除も確認を開く。線を外すは確認しない。系統は FILTER-08 のとおりである。線を外すは EDIT-12 のとおりである。

**制約** ダイアログを開いているあいだは背面を操作できないので出ない。線を引くモードのあいだは、タスク、ひし形と名前、カテゴリ行、グループ行のメニューと、「マイルストンを追加」は出さない。線の「線を外す」は出す。タスクバーとハンドルは線より先、マイルストンの当たりは帯の空きより先、線はチャートの空きより先に当たる。親バーはクリックを受けないので、チャート本体の空きと同じ項目になる。左の「マイルストン」、左の見出し、ツールバー、見出し、ヒントには出さない。表示期間の外は押せない。マイルストンの名前の上は追加にしない。

### EDIT-12 チャート上の前後の線

**操作** タスクを選んで「線を引く」を押す。⌘/Ctrl+L でも同じ。別のタスクバーをクリックすると、起点からそのタスクへ線を足す。起点をもう一度クリックする、Esc、「線を引く」、または ⌘/Ctrl+L で、結ばずに終わる。線にカーソルを合わせて Delete または Backspace を押すか、線を右クリックして「線を外す」を選ぶと、その 1 本を外す。

**挙動**

- モード: 選んでいないときはモードに入らない。入るとボタンに起点の名前が出て、画面上部は「次にクリックしたタスクを後続にします。Esc で中止」になる。起点は入ったときのタスクのままである。モードを終えると追随する線は消える。
- 追随: 起点の右端からカーソルへ、確定した矢印と同じ折れ線が通常の色で追随する。タスクバーの上ではそのバーの左端まで伸び、左の一覧の上ではチャートの左端で終わる。カーソルが乗ったタスクバーは、選択の枠とは別の輪郭になる。起点、親バー、ひし形は強調しない。
- 追加: 別のタスクバーをクリックすると、後続の `predecessors` に起点が入り、モードは残る。
- 失敗時: すでに結ばれている組と循環する組は保存せず、詳細パネルと同じ理由をモードのヒントの下に出す。モードは残る。
- 削除: 線を外すときは確認せず、その先行だけを外す。タスクは残り、前後のタスク同士はつながらない。重なった線は、カーソルに一番近い 1 本だけを太くして外す。
- 履歴: 線を足すのも外すのも、取り消しの 1 ステップである。

**制約** 見えていないタスクへは、この操作では線を引けない。詳細パネルの先行と後続は今どおり使える。モード中、チャートのドラッグはスクロールも移動も期間変更もマイルストンの日付変更もしない。ホイール、Shift+ホイール、⌘ または Ctrl と矢印ではスクロールでき、追随する線も動く。親バー、ひし形と名前、背景のクリックではモードは終わらない。ダブルクリックと Enter では詳細パネルの名前欄にフォーカスを移さない。タスクと、ひし形と名前の右クリックメニューは出さない。左の切れた名前の全文と一覧の幅は今どおりである。絞り込み、起点の削除、別ファイルを開くなどで選択が外れるとモードも終わる。⌘/Ctrl+L は、ダイアログ、検索欄、入力欄、選択欄では効かない。ボタンにフォーカスがあっても効く。修飾キーの無い L では始まらない。線の上の Delete と Backspace は、検索欄、入力欄、選択欄、ボタンにフォーカスがあるときは線を外さない。バーや、ひし形と名前の上では、今どおりタスクの削除確認である。両端が見えていない線は描けないので、この操作では外せない。ツールバーの「削除」はタスクを消す。線の端をドラッグして付け替えない。スキーマは変えない。

### EDIT-13 カテゴリとグループの名前

**操作** 左のカテゴリ行またはグループ行をダブルクリックする。右クリックの「名前を変更」でも同じ。

**挙動** 名前だけのダイアログが開く。保存する名前は前後の空白を除いたものである。空白だけなら、元の名前を残して閉じる。カテゴリ名が他のカテゴリと重なるとき、または同じカテゴリの中でグループ名が重なるときは、保存せず、重複であることを示す。保存すると `id` は変わらず、名前だけが変わる。取り消しは 1 ステップである。折りたたみは `id` を鍵にするので、改名しても開閉は残る。絞り込み、ズーム、スクロール、系統、選択は変えない。

**制約** チャート上の親バーからは開かない。線を引くモードのあいだは開かない。

### EDIT-14 複製

**操作** タスクのバー、または左のタスク行を右クリックし、「複製」を選ぶ。

**挙動** 「タスクを複製」ダイアログが開く。項目は詳細パネルと同じで、初期値は元タスクのタスク名、ノート、開始日、終了日、担当者、ステータス、進捗率、確度、対応マイルストン、先行である。後続の初期値は空である。候補には元タスクを含める。タスク名にフォーカスし、全文を選択する。同じ名前のままでも足せる。「追加」で、元タスクと同じグループの直後に新しいタスクを足す。ID は、カテゴリ、グループ、タスク、マイルストンの ID と重ならない UUID である。ダイアログで後続を足したときだけ、相手の先行に新しい ID が入る。追加後はそのグループとカテゴリを展開し、新しいタスクを選択して固定段の下に出る位置へ寄せ、系統を解除する。絞り込みは、新しいタスクを隠すものだけを外す。担当、ステータス、確度、期限、前後、マイルストン、タスク名の検索、ノートの検索を、足したタスクの値で判定する。取り消しは 1 ステップで、挿入と、ダイアログで足した後続をまとめて戻す。

**制約** 名前が空白だけ、日付が空または実在しない日、終了日が開始日より前、進捗率が 0 以上 100 以下の整数でない、循環する前後関係、存在しない先行なら足さず、理由を出してダイアログを開いたままにする。空白だけのノートは付けない。キャンセルと Escape では足さない。カテゴリとグループは選べず、別のグループへは動かない。ツールバーには出さない。線を引くモードのあいだは、タスクのメニューが出ないので複製もできない。スキーマは変えない。

### EDIT-15 タスクの並べ替え

**操作** 左のタスク行の左端の握りをドラッグし、離す。

**挙動** 同じグループの `tasks` 配列の順を変える。別のグループへ離したときは、そのグループへ移す。別のカテゴリでも同じである。あとから足したタスクを、既存のタスクのあいだに置ける。ドラッグ中は文書を変えず、左の一覧とチャートの行だけを仮の順で描く。挿入位置に線を出す。並べ替えが始まると、半透明のタスク行がポインタの縦位置に付いて動く。左の一覧では、仮の位置のその行は空けておく。離したときに1回だけ確定し、順または場所が変わったときだけ取り消しの1ステップになる。同じ位置へ戻したドロップは積まない。タスクの `id`、日付、確度、先行、担当は変えない。元のグループが空になっても残す。左の一覧は自動ではスクロールしない。

**制約** 複数タスクを一度に動かさない。カテゴリ行、親バー、折りたたんだカテゴリやグループの中へは入れない。並べ替えは左端の握りだけで始まる。握りを 3px を超えて動かすと、方向にかかわらず並べ替えが始まる。3px 以内で離してもタスクを選ばず、詳細パネルを開かない。握りを右クリックしても選択を変えず、メニューを出さない。握り以外をドラッグしても並べ替えは始まらない。名前が幅に収まらないときは NAV-05 のとおり全文が出て、名前は動かない。並べ替えになったドラッグでは選択を変えない。ノートボタンと、握り以外の右クリックメニューは今どおりである。チャート上のドラッグは NAV-01 と EDIT-02、EDIT-03 のままである。受けない位置で離したときは元の位置に戻す。絞り込みか系統で、移動元か移動先の兄弟が1件でも隠れているあいだは始めない。SYNC-03 で前回のファイルを開き終わるまでは始めない。スキーマは変えない。

### EDIT-16 カテゴリの並べ替え

**操作** 左のカテゴリ行の左端の握りをドラッグし、離す。

**挙動** `categories` 配列の順を変える。グループとタスクは、そのカテゴリの中に残る。折りたたんだカテゴリも、その行の握りをドラッグして順を変えられる。開閉は残る。ドラッグ中は文書を変えず、左の一覧とチャートの行だけを仮の順で描く。挿入位置に線を出す。並べ替えが始まると、半透明のカテゴリ行と、いま見えている配下のグループ行とタスク行が、上から順に積まれた塊でポインタの縦位置に付いて動く。折りたたんで出ていない配下は塊に入れない。左の一覧では、仮の位置の塊に入った行は空けておく。離したときに1回だけ確定し、順が変わったときだけ取り消しの1ステップになる。同じ位置へ戻したドロップは積まない。カテゴリ、グループ、タスクの `id` と中身は変えない。左の一覧は自動ではスクロールしない。

**制約** 複数カテゴリを一度に動かさない。グループの並びは変えない。タスクを別のグループや別のカテゴリへは動かさない。グループ行、タスク行、親バーは、この操作では掴めない。並べ替えは左端の握りだけで始まる。握りを 3px を超えて動かすと、方向にかかわらず並べ替えが始まる。握り以外をドラッグしても並べ替えは始まらない。名前が幅に収まらないときは NAV-05 のとおり全文が出て、名前は動かない。ダブルクリックの名前変更、右クリックの「名前を変更」、三角の折りたたみは今どおりである。チャート上のドラッグは NAV-01 のままである。カテゴリ全体の縦範囲の外、または固定されている見出しの上で離したときは元の位置に戻す。固定されているカテゴリ行の握りからも始められる。絞り込みか系統でカテゴリが1件でも行に出ていないあいだは並べ替えを始めない。SYNC-03 で前回のファイルを開き終わるまでは並べ替えも始めない。スキーマは変えない。

### EDIT-17 グループの並べ替え

**操作** 左のグループ行の左端の握りをドラッグし、離す。

**挙動** 同じカテゴリの `groups` 配列の順を変える。別のカテゴリのグループの境界へ離したときは、そのカテゴリへ移す。タスクは、そのグループの中に残る。折りたたんだグループも、その行の握りをドラッグして順を変えられる。開閉は残る。ドラッグ中は文書を変えず、左の一覧とチャートの行だけを仮の順で描く。挿入位置に線を出す。並べ替えが始まると、半透明のグループ行と、いま見えている配下のタスク行が、上から順に積まれた塊でポインタの縦位置に付いて動く。折りたたんで出ていない配下は塊に入れない。左の一覧では、仮の位置の塊に入った行は空けておく。離したときに1回だけ確定し、順または場所が変わったときだけ取り消しの1ステップになる。同じ位置へ戻したドロップは積まない。カテゴリ、グループ、タスクの `id` と中身は変えない。左の一覧は自動ではスクロールしない。

**制約** 複数グループを一度に動かさない。カテゴリの並びは変えない。カテゴリを別のカテゴリの中へは入れない。カテゴリ行、タスク行、親バーは、この操作では掴めない。並べ替えは左端の握りだけで始まる。握りを 3px を超えて動かすと、方向にかかわらず並べ替えが始まる。握り以外をドラッグしても並べ替えは始まらない。名前が幅に収まらないときは NAV-05 のとおり全文が出て、名前は動かない。ダブルクリックの名前変更、右クリックの「名前を変更」、三角の折りたたみは今どおりである。チャート上のドラッグは NAV-01 のままである。受けない位置で離したときは元の位置に戻す。移した先に同じグループ名があるときは確定しない。移すと元のカテゴリのグループが0件になる位置は受けない。折りたたんだカテゴリの中へは入れない。絞り込みか系統で、移動元か移動先の兄弟グループが1件でも隠れているあいだは始めない。親のカテゴリを折りたたんでいるあいだは、グループ行が無いので始めない。SYNC-03 で前回のファイルを開き終わるまでは並べ替えも始めない。スキーマは変えない。

### EDIT-18 カテゴリとグループの追加

**操作** 左のカテゴリ行またはグループ行を右クリックし、「下にカテゴリを追加」、「グループを追加」、または「下にグループを追加」を選ぶ。

**挙動** 名前だけのダイアログが開く。保存すると、カテゴリの追加は右クリックしたカテゴリの直後に足す。中にはタスク0件のグループを1つ作り、名前は「グループ」にする。カテゴリ行からのグループ追加はそのカテゴリの末尾、グループ行からはその直後に入れる。`id` はカテゴリ、グループ、タスク、マイルストンと重ならない UUID である。取り消しは1回である。絞り込み、系統、選択は変えない。

**制約** ツールバーにはボタンを足さない。ダブルクリックは名前の変更のままである。空白だけの名前と、重複する名前は追加しない。ダイアログは開いたまま理由を出す。線を引くモードのあいだは開かない。スキーマは変えない。

### EDIT-19 カテゴリとグループの削除

**操作** 左のカテゴリ行またはグループ行を右クリックし、消せるときだけ出る「削除」を選ぶ。

**挙動** 確認してから消す。グループは、タスクが0件で、同じカテゴリに他のグループがあるときだけ消せる。カテゴリは、配下のタスクが0件で、他にカテゴリがあるときだけ消せる。中の空グループも一緒に消える。取り消しは1回である。

**制約** Delete キーとツールバーの「削除」は、選んだタスクのままである。カテゴリとグループは選択されないので、キーでは消さない。線を引くモードのあいだはメニューを出さない。スキーマは変えない。

### EXPORT-01 形式

**操作** ☰ の「書き出し」で HTML か SVG を選び、「書き出す」を押す。

**挙動** 選んだ形式のファイルを保存する。既定の選択は HTML である。キャンセルでは何も書かない。

**制約** 生成はフロントで行い、画面の Canvas を画像化しない。

### EXPORT-02 対象の行と期間

**操作** 絞り込み、折りたたみ、系統を使った状態で書き出す。

**挙動** 見えている行を、スクロールで隠れている分も含めて書く。書き出しは行を固定せず、通常の並びのまま書く。期間は、その行と書き出すマイルストンから決め直し、前後に画面と同じ余白を付ける。1日あたりの幅と、日・週・月の粒度は画面と同じである。マイルストン帯はグループの並びを保ち、名前は全文で書く。全文が同じグループの次のひし形を越えるときは、そのグループの中だけで段を増やす。FILTER-11 で隠したグループの線は書き出さない。その日付は期間の端に使わない。前後の線、イナズマ線、非稼働日、親バー、超過、使っている絞り込みの一覧も入れる。親バーとタスクバーの名前の置き方は画面と同じである。今日の縦線は書き出しに足さない。

**制約** 画面全体の期間や、隠れているタスクは入れない。マイルストンの選び方は [データ仕様](data-format.md#書き出しファイル) のとおりである。

### EXPORT-03 上限

**操作** 大きいスケジュールを書き出す。

**挙動** 行数が 10,000 を超える、幅が 200,000px を超える、または高さが 50,000px を超えるときは、ファイルを書かずに理由を出す。デスクトップ版は、できた内容が 10MB を超えるときも保存しない。

**制約** 上限を超えたときは、絞り込みや折りたたみで対象を減らす。

### EXPORT-04 ファイル名

**操作** 保存ダイアログに出る提案名を見る。

**挙動** スケジュールのタイトルから、パスに使えない文字と制御文字を除いた名前に `.html` または `.svg` を付ける。空、または Windows の予約名だけなら `schedule` を使う。

**制約** デスクトップ版は保存ダイアログで名前を変えられる。ブラウザ版はダウンロード名になる。

### SET-01 表示サイズ

**操作** 設定の「表示」で「自動」「50%」「75%」「100%」「125%」「150%」「200%」を選ぶ。⌘ または Ctrl と + または = で一段大きくする。⌘ または Ctrl と − で一段小さくする。テンキーの + と − も同じである。Shift を押して文字が + になる押し方も拡大である。

**挙動** 文字、行、ボタンの大きさを変える。初回起動の既定は 100% である。保存値が無いときも 100% として読む。「自動」は、幅 1100px、高さ 780px を基準に、それより大きいウィンドウで最大 200% まで広げる。基準以下では 100% のままである。行の密度は「標準」と「詰める」から選び、チャートの行の高さだけを変える。イナズマ線の表示のオンオフと、左一覧の追加列も同じ「表示」に置く。選んだ値（`auto` を含む）は localStorage に残り、次の起動でも使う。ショートカットは一段ずつ変え、押し続けは keydown の繰り返しで、端では止まる。固定の段は隣へ進む。200% で拡大しても 200%、50% で縮小しても 50% のままである。自動のときは、その場の倍率を小数第2位で段と比べ、自動をやめて固定の段にする。一致する段は、その段にいるものとして隣へ進む。拡大は今の倍率より大きい段のうちいちばん小さい段で、無ければ 200% を保存して自動をやめる。縮小は今の倍率より小さい段のうちいちばん大きい段で、無ければ 50% にする。端で段が変わらないときは保存値も変えない。設定の「表示」が開いていれば、選択は新しい段を示す。検索欄、入力欄、選択欄、ボタン、開いているダイアログの中でも変わる。このキーでは、ブラウザのページズームとデスクトップ版の WebView のズームは起こさない。右クリックメニューは閉じる。線を引くモードは終わらない。追加列は、開始と終了を `09/19` のように月と日で、日数を `12日`、進捗を `30%` で出す。開始、終了、日数、進捗、超過、担当は、行をまたいで同じ位置に揃う。超過が無い行もその幅を空ける。担当が列の幅を超えるときは省略し、マウスを乗せると全文が出る。初期はどれも出さない。ダイアログの幅と文字も表示サイズに追従する。

**制約** チャートのズーム（NAV-02）とは別である。固定値は 50% 未満、200% 超にはできない。修飾キーの無い +、=、−、Alt が付いた組み合わせ、Shift で `_` になる押し方、⌘0 や Ctrl+0 では変えない。スケジュール、取り消し、選択、絞り込み、折りたたみ、1日あたりの幅、左一覧の基準幅は変わらない。デスクトップ版では、同じオリジンの localStorage を他のウィンドウが読み直す。

### SET-02 メンバー

**操作** 設定の「メンバー」で、「取り込み…」でカタログを足す。一覧のラジオボタンで使うカタログを選ぶ。「選択を解除」で未選択に戻す。各カタログの「外す」で消す。

**挙動** メンバー JSON を検証してカタログとして保存する。カタログの ID はファイル名から作り、同じ ID のカタログが既にあるときは上書きを確認する。使用中のカタログ名は、設定と見出しに出る。「外す」はそのカタログを消し、使用中だったなら未選択に戻す。初回はサンプルのメンバーを一度だけ入れる。削除したあとは、自動では戻さない。

**制約** スケジュール JSON にはメンバーを書かない。1件の上限は 2MB。読み込みに失敗すると見出しに「メンバー設定エラー」を出す。ブラウザの保存領域に書けないときは、その旨を設定画面に出す。デスクトップ版では、取り込みや選択の変更を他のウィンドウへ知らせ、受けた側はアプリデータを読み直す。

### SET-03 稼働日

**操作** 設定の「稼働日」で「取り込み…」または「外す」を押す。

**挙動** カレンダー JSON を1件だけ保存する。既にあるときは上書きを確認する。未設定のときは「使用中: 未設定（土日を塗る）」と出る。外すと未設定に戻る。検証や読み込みに失敗したときは土日表示に戻し、見出しに「カレンダー設定エラー」を出す。

**制約** スケジュール JSON には書かない。タスクの日付は暦日のままである。上限は 2MB。ブラウザの保存領域に書けないときは、本文と表示名のどちらも残さない。設定画面にその旨を出す。デスクトップ版では、取り込みや外しを他のウィンドウへ知らせ、受けた側はアプリデータを読み直す。

### SET-04 配色

**操作** 設定の「表示」で「システム設定に合わせる」「ライト」「ダーク」を選ぶ。

**挙動** 画面全体の色を変える。ライトは従来どおりの明るい配色である。ダークは暗い灰を基調にし、文字と区切りが読める配色にする。HTML と SVG の書き出しは、書き出した時点の画面と同じ配色にする。「システム設定に合わせる」では OS の明るさ設定（`prefers-color-scheme`）に従い、ダークならダーク、それ以外はライトにする。この選択中に OS の設定が変わったら、再起動しなくても画面を追従させる。「ライト」と「ダーク」は OS の設定より優先する。選んだ値は localStorage に残り、次の起動でも使う。「システム設定に合わせる」に戻すと保存値は消える。

**制約** チャートのズーム（NAV-02）と表示サイズ（SET-01）とは別である。スケジュール JSON には書かない。デスクトップ版では、同じオリジンの localStorage を他のウィンドウが読み直す。

### SET-05 JSON作成スキルを置く

**操作** 設定の「JSON作成スキルを置く」で、Cursor と Claude Code のどちらへ置くか、ユーザー全体か指定したフォルダかを選び、「置く」を押す。指定したフォルダのときは「フォルダを選ぶ…」で1つ示す。「外す」で、同じ選び方の場所から3つを削除する。

**挙動** `write-schedule`、`write-members`、`write-calendar` の3つを、その版のアプリに同梱されている内容のまま置く。Cursor へ置くときは `~/.cursor/skills/<name>/` または `<フォルダ>/.cursor/skills/<name>/` である。Claude Code へ置くときは `~/.claude/skills/<name>/` または `<フォルダ>/.claude/skills/<name>/` である。`<name>` は上の3つだけである。両方を選んだときは同じ内容を両方へ置く。`~/.cursor` や `~/.claude` が無くても、選べば親ディレクトリを作る。先に同名フォルダがあれば、置き換えるか設定の中で確認する。中身はマージしない。終わったら置いたパスを示す。Claude Code で指定フォルダへ置き、かつ `~/.claude/skills/` に同名があるときは、個人用がプロジェクト用より先に使われる旨を出す。初回起動では書かない。「外す」は、置くのと同じツールと範囲で、存在する3つだけを消す。消す前に確認する。無いパスはそのままにし、外したパスを示す。skills フォルダや別名のスキルは残す。スキルフォルダ自体がシンボリックリンクのときは、リンクだけ外し、リンク先は消さない。`.cursor` と `.claude` と `skills` がシンボリックリンクのときは置かず、外さない。入れ替えに失敗したときは、そのスキルフォルダの元の中身を残す。

**制約** デスクトップ版だけである。ブラウザ版では同じ欄を出すが、置けない。インストーラーはホームやプロジェクトへコピーしない。git には入れない。検証スクリプトは Node.js で動かす。`implement-change` など開発用スキルは置かない。

| カテゴリ・グループの追加 | 左の行の右クリックの追加項目 | 「追加」で足す。無効なら開いたまま。閉じると破棄 |

| マイルストン削除 | ひし形またはその右の名前の右クリックの「削除」 | 「削除」で消し、指しているタスクの対応を外す。「キャンセル」で残す |
| 設定 | ☰ の「設定」 | 表示（サイズと配色）、メンバー、稼働日、JSON作成スキルを置く。メンバーとカレンダーと JSON スキルの上書き確認は設定の中に出る |
| JSON | ☰ の「JSON を表示」 | 閉じるだけ |

| 書き出し | ☰ の「書き出し」 | HTML か SVG を選んで「書き出す」 |

| ファイルが更新されています（監視） | 外部更新があり、未保存か編集中 | 「読み直す」「画面の編集を残す」 |

| ファイルが見つかりません | 起動時、前回のファイルが無く未保存も無い | 「閉じる」。サンプルにする |
| 復旧用の控え | 控えが壊れている、またはファイルはあるが検証できない | 「閉じる」「控えを破棄」 |
