# 操作マニュアル

schedule-viewer の手順は、次の三つに分けてあります。ボタン名や色の意味が文書と違って見えたときは、挙動を定めている [外部仕様](external-spec.md) を確認してください。

| 文書 | 読むとき |
| --- | --- |
| [はじめに](user-manual/getting-started.md) | 入手、起動、ファイルを開いて保存するまでを短く知りたいとき |
| [チュートリアル](user-manual/tutorial.md) | LLM とスキルで JSON を作り、画面で直し、MCP で一部を直して取り込み直す流れを追いたいとき |
| [全機能](user-manual/features.md) | 絞り込み、編集、設定、ショートカットなど、操作を網羅的に調べたいとき |

はじめにを読んだあと、スケジュールを LLM と作るならチュートリアルへ進みます。画面の細かい操作は全機能を見ます。
