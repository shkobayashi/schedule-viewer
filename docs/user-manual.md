# 操作マニュアル

schedule-viewer を使う人向けの手順です。ボタン名や色の意味がこの文書と違って見えたときは、挙動を定めている [外部仕様](external-spec.md) を確認してください。

## できること・しないこと

このアプリは、用意したスケジュール JSON を WBS とガントチャートとして表示し、絞り込んだり、その場で直したりするためのものです。

次のことはしません。

- 稼働日を数えて期間を計算すること
- 前後関係に合わせて日付を自動で動かすこと
- アプリの中から LLM にスケジュールを作らせること
- タスクの順番を入れ替えること。順番は JSON に書いた順のままです

## インストールと起動

[GitHub Releases](https://github.com/shkobayashi/schedule-viewer/releases) から、使う OS 用のファイルをダウンロードします。`SHA256SUMS` で配布物の SHA-256 を確認できます。

- Ubuntu 22.04 以降では、`schedule-viewer_X.Y.Z_amd64.deb` を `sudo apt install ./schedule-viewer_X.Y.Z_amd64.deb` で入れ、`schedule-viewer` で起動します
- Windows では、`schedule-viewer_X.Y.Z_x64-setup.exe` を実行し、スタートメニューから起動します

macOS 用の自動ビルドはまだありません。使う Mac の上でアプリをビルドする必要があります。手順は [開発ガイド](development.md#配布用ビルド) にあります。

このアプリには、デスクトップ版とブラウザ版があります。ふだん使うのは、上の手順で入れるデスクトップ版です。ブラウザ版は開発中の確認用で、リポジトリで `npm run dev` を実行して開きます。ブラウザ版では、ファイルの開き方や保存のしかたなどが違います。違いは「困ったとき」にまとめてあります。

## 画面の見かた

```
+--------------------------------------------------------------------------------------------+
| ☰  タイトル [状態]  検索  絞り込み  系統  追加  マイルストン追加  削除  −  週表示  ＋  Fit |
| 操作のヒント                                                                               |
+--------------------------+-----------------------------------------------------------------+
| WBS / タスク             | 日付                                                            |
| マイルストン             | マイルストン                                                    |
| カテゴリ                 | 親バー、タスクバー、矢印、今日の線                              |
|   グループ               |                                                                 |
|     タスク               |                                                                 |
+--------------------------+-----------------------------------------------------------------+
```

左が名前の一覧、右が時間軸です。上下のスクロールは左右で揃います。

左上のタイトルと、その右に並ぶ状態の表示をまとめて、この文書では「見出し」と呼びます。状態の表示は、次のどれか1つです。

| 表示 | 意味 |
| --- | --- |
| サンプルデータ | まだファイルを開いていない |
| 未保存 | 画面の内容が、ファイルに書いた内容と違う |
| ファイル名 | 保存済み。開いているファイルの名前 |
| 保存済み | 保存済みだが、表示するファイル名が無い |
| ファイルを反映しました | 別のプログラムが書き換えた内容を、たった今画面に反映した。しばらくすると消える |

見出しには、状況に応じて次も並びます。

- 「ファイルに更新あり — 読み直す」。別のプログラムによる変更を、まだ画面に反映していません
- 使用中のメンバーカタログの名前。カタログについては「設定」を見てください
- 「メンバー設定エラー」「カレンダー設定エラー」。設定の読み込みに失敗しています。マウスを乗せると理由が出ます

☰ を押すと、「開く」「保存」「別名保存」「書き出し」「JSON を表示」「差分を表示」「設定」が出ます。

## ファイルを開く・保存する

1. ☰ の「開く」でスケジュール JSON を選びます
2. 中身に問題が無ければ、画面がその内容に替わります
3. 問題があれば理由が表示され、それまでの画面はそのまま残ります

未保存のときに別のファイルを開こうとすると、「破棄して開く」か「キャンセル」かを聞かれます。破棄すると、保存していない変更は失われます。

「保存」は、開いているファイルに上書きします。まだ保存先が無ければ、保存先を聞きます。「別名保存」は、いつも保存先を聞きます。

「JSON を表示」は、今の内容を見るだけで、ファイルには書きません。

「差分を表示」は、今の画面と、開いているファイルの中身との違いだけをテキストで出します。「コピー」で全文を写し、LLM に渡す変更の指示に使えます。ファイルには書きません。まだファイルを開いていないときとブラウザ版では、「比べるファイルがありません」と出ます。保存したあとに開くと「差はありません」になります。開く、保存、別名保存の途中は押せません。

## 表示を動かす

- チャートをドラッグすると、縦横にスクロールします
- ホイールで縦に、Shift を押しながらのホイールで横に動きます。日付の行の上では、ホイールだけでも横に動きます
- Ctrl または ⌘ を押しながらホイールを回すと、マウスの位置を基準に拡大・縮小します。− と ＋ でも変えられます
- 拡大率に応じて、表示が「日表示」「週表示」「月表示」に切り替わります
- 「Fit」を押すと、スケジュール全体の期間が画面の幅に収まる大きさになります
- 左の三角で、カテゴリやグループを畳めます。畳んでも、その行のバーは残ります
- 左の名前が途中で切れているときは、その名前を横にドラッグすると続きを読めます
- 左の一覧とチャートの境界を横にドラッグすると、一覧の幅を変えられます。ダブルクリックで元の幅に戻ります。ウィンドウを狭めたときは表示だけ縮み、広げると戻ります

## 絞り込む

画面上部の検索欄と絞り込みの欄は、組み合わせて使えます。すべての条件を満たすタスクだけが残ります。残ったタスクが無いグループは、行ごと隠れます。

「前後」と「マイルストン」の絞り込みは、タスクが持つ次の情報を使います。

- 先行・後続：タスクには、先に済ませておくタスクを登録できます。登録した相手をそのタスクの先行、逆向きに見た相手を後続と呼びます。編集ダイアログの「先行タスク」「後続タスク」で設定します
- 対応マイルストン：タスクごとに、関係するマイルストンを1つ結び付けられます。編集ダイアログの「対応マイルストン」で選びます

| 欄 | 使い方 |
| --- | --- |
| タスク名で検索 | 名前にその文字を含むタスク |
| ノートで検索 | ノートにその文字を含むタスク。ノートが無いタスクは残らない |
| 担当者 | 「割り当てなし」は、担当者のいないタスクと、担当者の ID がメンバーに見つからないタスクの両方 |
| ステータス | 「完了以外」は、完了していないタスク |
| 期限 | 「期限超過」は、今日より前に終わる未完了のタスク |
| 前後 | 「前後: 破綻のみ」は、後続が先行の終了より前に始まっている組 |
| マイルストン | 「なし」は、対応マイルストンが無いタスク。名前を選ぶと、そのマイルストンに結び付いたタスクだけ |

タスクを選んで「系統」を押すと、そのタスクの前と後につながるタスクだけが残ります。ボタンには、起点にしたタスクの名前が出ます。もう一度押すと解除します。

絞り込みを変えると、選んでいたタスクの選択は外れます。

## 色と線の見かた

| 見た目 | 意味 |
| --- | --- |
| 灰色のバー | 未着手 |
| 薄い青のバーと、その中の濃い部分 | 進行中。濃い部分が進捗率 |
| 緑のバー | 完了 |
| 赤いバー | 期限超過。終了日が今日なら赤くしない |
| 破線の枠と、上端の黄色 | 割り当てなし |
| 紫の点線の枠と、上端の紫 | メンバー不明。ID も出る |
| マイルストンより右の半透明の赤と、行の「超過」 | 対応マイルストンの日を過ぎている。当日は超過にしない |
| 半分の高さのバー | カテゴリやグループの範囲。配下のタスクが途切れている期間は薄い |
| オレンジ色の折れ線 | 今日の位置（イナズマ線）。遅れている行では終了日まで左へ、着手済みで開始が未来の行では開始日まで右へ折れる |
| 矢印 | 先行から後続へ引く線。後続が先行の終了より前に始まるときは赤い |
| 薄い灰色の背景 | 非稼働日。カレンダーを入れるまでは土日。月表示では塗らない |

## 編集する

タスクを選ぶのは、右のバーをクリックしたときと、タスクを右クリックしたときです。左の名前を左クリックしても選択されません。

- 移動するには、⌘ または Ctrl を押しながらバーを横にドラッグします。離したときに確定します。ふつうのドラッグはスクロールのままです
- 期間を変えるには、選んだバーの左右の端をドラッグします。1日より短くはできません
- バーをダブルクリックすると、編集ダイアログが開きます。選択中なら Enter でも開きます。名前、ノート、日付、担当、ステータス、進捗、対応マイルストン、先行、後続を変えられます
- タスクのバー、または左のタスク行を右クリックすると、「編集」「ノート」「系統を表示」または「系統を解除」「削除」が出ます。左の行は、右クリックしたときだけ選択されます
- マイルストンのひし形を右クリックすると、「編集」と「削除」が出ます。右クリックしても、タスクの選択は変わりません
- 先行と後続の候補は、一度に50件まで出ます。多いときは、名前で検索して絞り込みます
- ノートは、左のノートアイコンからも開けます。アイコンの色で、ノートの有無が分かります。空白だけにして保存すると、ノートは消えます
- マイルストンの日付は、ひし形を横にドラッグして変えます。名前と日付は、ひし形をダブルクリックするか、右クリックの「編集」で変えます。名前が空白だけなら、元の名前のまま残ります
- 「追加」では、既存のカテゴリとグループを選び、そのグループの末尾にタスクを足します。終了日に指定した日も期間に含まれます
- 「マイルストン追加」では、名前と日付を指定して足します。マイルストンが無くても押せます。開いたときの名前は空で、日付は今日です。ひし形は、指定した日付の位置に出ます。名前が空白だけ、または日付が空のときは足さず、ダイアログは開いたままです。同じ名前と日付でも足せます。キャンセルと Escape でも足しません
- 「削除」は、タスクを選んでから押します。Delete または Backspace でも同じ確認が開きます。確認のあとに消えます。消したタスクとの前後関係は外れますが、その前後にあったタスク同士を自動でつなぎ直すことはしません。ツールバーの「削除」と Delete では、マイルストンは消えません
- ひし形の右クリックの「削除」では、確認のあとにマイルストンが消えます。そのマイルストンを指していたタスクは、対応だけが外れ、日付は変わりません。絞り込んでいたマイルストンを消すと、マイルストンの絞り込みは「すべて」に戻ります。選択と系統は残ります。取り消しても、絞り込みは「すべて」のままです
- 取り消しは ⌘/Ctrl+Z、やり直しは ⌘/Ctrl+Shift+Z か Ctrl+Y です。戻せるのは確定した編集だけで、最大100件です。絞り込みやスクロールは戻りません

検索欄やダイアログに文字を入力しているあいだは、取り消し、やり直し、Enter での編集、Delete での削除には使われません。⌘/Ctrl+S、⌘/Ctrl+Shift+S、⌘/Ctrl+O、⌘/Ctrl+F は、検索欄にフォーカスがあっても効きます。ダイアログが開いているあいだは、これらも効きません。

## 書き出す

1. 残したい行だけになるように、絞り込み、折りたたみ、系統を使います
2. ☰ の「書き出し」で HTML か SVG を選びます
3. 「書き出す」を押して保存します

書き出しに入るのは、絞り込みや折りたたみで隠していない行と、その期間に関係するマイルストンです。画面の外にスクロールしている行も入ります。絞り込みで隠したタスクは入りません。日・週・月の表示単位は、画面と同じです。

行が 10,000 を超えるとき、または図が横 200,000px か縦 50,000px を超えるときは、保存せずに理由を表示します。絞り込みや折りたたみで範囲を減らしてください。

## 設定

☰ の「設定」に、3つの欄があります。

- 「表示」では、文字と行とボタンの大きさと、ライト・ダーク・システムに合わせる配色を変えます。「自動」か、50% から 200% を選びます。チャートのズーム（Ctrl または ⌘ とホイール）とは別の設定です
- 「メンバー」では、メンバー JSON を取り込みます。取り込んだ1件を「カタログ」と呼びます。使うカタログを1つ選ぶと、タスクの担当者 ID が名前で表示されます。メンバーはスケジュールのファイルには書きません
- 「稼働日」では、休日と振替出勤を書いた JSON を1件取り込みます。未設定のときは土日を塗ります。タスクの日付の計算は変わりません

同じファイル名のカタログや、すでにあるカレンダーを取り込むときは、上書きしてよいかを聞きます。

## ほかのプログラムがファイルを書き換えたとき

デスクトップ版では、開いているファイルが書き換えられていないかを、アプリが定期的に確かめています。

- 未保存の編集が無く、編集ダイアログも開いていなければ、書き換えられた内容に問題が無い限り、画面に反映します。見出しにしばらく「ファイルを反映しました」と出ます
- 未保存の編集があるときは、「読み直す」か「画面の編集を残す」かを選びます。残したあとは、見出しの「ファイルに更新あり — 読み直す」から同じ確認に戻れます
- 「保存」を押したときに、開いたあとでファイルが書き換えられていれば、「上書き保存」「別名保存」「取り消し」から選びます

## 閉じたあとに、また開くとき

デスクトップ版では、開いていたスケジュール JSON を覚えています。次に起動すると、そのファイルを開き直します。保存して閉じていても、未保存のまま閉じていても同じです。絞り込み、折りたたみ、ズーム、スクロール、系統、選択は戻しません。

未保存のまま閉じたときは、保存していない編集もアプリの中に残します。開いているファイルそのものは書き換えません。次に起動したとき、ファイルが閉じたときのままなら、閉じる前の編集中の状態に戻ります。そのあいだにファイルが書き換えられていれば、「ファイルを開く」か「未保存の編集を戻す」かを選びます。

前回のファイルが無く、未保存の編集も無いときは、そのことを知らせてサンプルを表示します。未保存の編集があるときは、その内容を画面に戻し、ファイルが無いことを知らせます。「ファイルを開く」では、覚えたパスを直接開かず、フォルダから選び直します。作業中にファイルが読めなくなったときも、続けて読めなくなってから、同じ選び直しになります。キャンセルすると、画面の内容は残ります。

サンプルを編集したまま閉じるときは、戻す先のファイルが無いので次回はサンプルのままです。破棄して閉じてよいかを確認します。

## LLM でスケジュール、メンバー、カレンダーを作る

スケジュール JSON、メンバー JSON、カレンダー JSON は、このリポジトリにあるスキルを使って LLM に作らせます。スキルは、LLM のエージェントに渡す手順書と検証スクリプトをまとめたフォルダです。スケジュールを作る側のリポジトリへコピーして使います。

スケジュール JSON は `.cursor/skills/write-schedule` で作ります。担当者を付けるときは、メンバー JSON にある ID だけを使います。ID の一覧を渡していないと、スキルは JSON を作らず、一覧が足りないと伝えます。

メンバー JSON は `.cursor/skills/write-members` で作ります。渡した ID と表示名だけを書き、ID は名前から推測しません。

カレンダー JSON は `.cursor/skills/write-calendar` で作ります。渡した日付だけを書き、祝日は推測しません。

どのスキルも、書いたあとに同梱の検証スクリプトで中身を確かめます。形式の詳細は [データ仕様](data-format.md) にあります。画面で日付やタスクを直したあとは、「差分を表示」のテキストを渡すと、スケジュール全文を二つ渡さずに変更だけを伝えられます。

## 困ったとき

**ファイルが開けない。** ダイアログに出るエラーの内容を確認します。問題の場所は、カテゴリ、グループ、タスクの名前で示されます。開けるのは schemaVersion 3 だけです。担当者を名前で書いた古い形式（schemaVersion 2）は開けません。

**担当が「メンバー不明」になる。** 設定の「メンバー」で、その ID を含むカタログを選んでください。カタログを選んでいないときも、ID がある担当はメンバー不明になります。

**「メンバー設定エラー」「カレンダー設定エラー」が出る。** 見出しのその表示にマウスを乗せて、理由を確認します。カレンダーのエラーが直るまでは、土日だけを塗ります。

**Windows で SmartScreen が出る。** インストーラは署名していません。入手元が GitHub Releases であることを確認してから進めてください。

**書き出せない。** 行数か、図の幅か高さが上限を超えています。絞り込みや折りたたみで行を減らしてください。

**ブラウザ版とデスクトップ版の違い。** ブラウザ版では、「開く」がファイル選択、「保存」と「書き出し」がダウンロードになります。別のプログラムがファイルを書き換えても、画面には反映しません。閉じたあとに前回のファイルや未保存の編集を戻すこともありません。メンバーと稼働日の設定は、そのブラウザの中に残ります。
