# 操作マニュアル

schedule-viewerの操作手順です。ボタン名や色の意味がこの文書と違って見えたときは、挙動を定めている[外部仕様](external-spec.md)を確認してください。

## できること

このアプリは、用意したスケジュールJSONをWBSとガントチャートとして表示できます。絞り込みと、その場での修正も、このアプリの役割です。

稼働日を数えて期間を出すことはしません。前後関係に合わせて日付を自動で動かすこともありません。アプリの中からLLMにスケジュールを作らせることもありません。タスクの順番は、左の一覧でタスク行の左端の握りをドラッグして変えられます。別のグループや別のカテゴリへも移せます。グループの順番は、左のグループ行の左端の握りをドラッグして変えられます。別のカテゴリへも移せます。カテゴリの順番は、左のカテゴリ行の左端の握りをドラッグして変えられます。握り以外をドラッグしても、順番は変わりません。絞り込みや系統で兄弟が隠れているあいだは、並べ替えや移動は始まりません。

## インストールと起動

入手先は[GitHub Releases](https://github.com/shkobayashi/schedule-viewer/releases)です。使うOS用のファイルを、そこからダウンロードします。配布物のSHA-256は`SHA256SUMS`で確認できます。

Ubuntu 22.04以降で使うファイルは`schedule-viewer_X.Y.Z_amd64.deb`です。導入は`sudo apt install ./schedule-viewer_X.Y.Z_amd64.deb`で行います。起動コマンドは`schedule-viewer`で、Windowsの配布物は`schedule-viewer_X.Y.Z_x64-setup.exe`です。Windowsではそのファイルを実行してください。起動場所はスタートメニューです。

macOS用の自動ビルドはまだありません。使うMacの上でアプリをビルドする必要があります。手順の場所は[開発ガイド](development.md#配布用ビルド)です。

このアプリにはデスクトップ版とブラウザ版があります。ふだん使うのは、上の手順で入れるデスクトップ版です。ブラウザ版は開発中の確認用で、リポジトリで`npm run dev`を実行して開きます。ブラウザ版で違うのは、ファイルの開き方や保存のしかたです。違いは「困ったとき」にまとめてあります。

## 画面の見かた

```
+--------------------------------------------------------------------------------------------+
| ☰  タイトル [状態]  [名前|ノート] 検索  絞り込み              今日 日週月 全体  ? |
| 系統  線を引く  追加  マイルストン追加  削除  取り消し  やり直し                      |
| [担当: 佐藤 ×] …  すべて解除   （条件があるときだけ）                                      |
+--------------------------+-----------------------------------------------------------------+
| WBS / タスク             | 日付                                                            |
| マイルストン             | マイルストン                                                    |
| カテゴリ                 | カテゴリ・グループの期間を示す親バー、タスクバー、矢印、今日の線 |
|   グループ               |                                                                 |
|     タスク               |                                                                 |
+--------------------------+-----------------------------------------------------------------+
```

左が名前の一覧で、右が時間軸です。上下のスクロールは左右で揃います。

左上には、スケジュールのタイトルだけが出ます。ファイル名、保存の状態、メンバーカタログ、表示の粒度、件数は画面下の状態バーに出ます。件数は「全件数中、表示件数」の順です。未保存のときは状態バーに「未保存」が出ます。押すと差分ダイアログが開きます。別のプログラムが書き換えた内容を画面に反映した直後は、画面の隅に「ファイルを反映しました」と数秒だけ出ます。別のプログラムによる変更をまだ反映していないときは、状態バーに「ファイルに更新あり — 読み直す」が出ます。メンバーまたはカレンダーの設定の読み込みに失敗しているときは、状態バーに注意の色で出ます。押すと設定の該当欄が開きます。

☰を押すと、次の項目が出ます。「開く」・「新しいウィンドウで開く」・「保存」・「別名保存」・「書き出し」・「JSONを表示」・「差分を表示」・「ショートカット一覧」・「設定」です。?キーとF1でもショートカット一覧を開けます。⌘またはCtrl+Kでコマンドパレットを開き、操作を名前で探して実行できます。macOSのデスクトップ版では、画面上部のメニューバーからも、同じファイル操作と表示の切り替え、ウィンドウの閉じる（⌘W）と最小化（⌘M）が選べます。編集の取り消しは、入力欄にフォーカスがあるときは文字入力の取り消し、それ以外はスケジュールの履歴を戻します。

## ファイルを開く・保存する

☰の「開く」でスケジュールJSONを選びます。中身に問題が無ければ、画面はその内容に替わります。問題があるときに出るのは理由です。それまでの画面は残ります。

デスクトップ版では、「新しいウィンドウで開く」で今のウィンドウを残したまま、別ウィンドウにスケジュールを開けます。⌘またはCtrl+Shift+Oでも同じです。未保存でも確認は出ません。検証に失敗したときは、今のウィンドウにエラーが出て、ウィンドウは増えません。同じファイルを複数のウィンドウで開けます。別のウィンドウで同じファイルが更新されたときは、今のウィンドウの隅にファイル名と「反映した」か「確認待ち」が出ます。押すと、更新したウィンドウが前面になります。「反映した」は数秒で消えます。「確認待ち」は、その確認が終わると消えます。アプリが他のソフトの後ろにあるときは、同じ内容を OS の通知でも出します。終了は、開いているウィンドウすべての閉じる確認のあとです。キャンセルすると、どのウィンドウも閉じません。

未保存で別のファイルを開くときの確認は、「破棄して開く」か「キャンセル」かです。破棄すると、保存していない変更は失われます。

「保存」は、開いているファイルへの上書きです。まだ保存先が無ければ、保存先を聞きます。「別名保存」が聞くのは、いつも保存先です。

「JSONを表示」は、今の内容を見るだけで、ファイルには書きません。「差分を表示」は、今の画面と開いているファイルとの違いだけをテキストで出します。⌘またはCtrl+Shift+Dで全文をコピーできます。未保存のときは、画面下の状態バーの「未保存」を押しても差分を開けます。「コピー」で全文を写せます。写したテキストの使い道は、LLMへ渡す変更の指示です。ファイルには書きません。まだファイルを開いていないときとブラウザ版では「比べるファイルがありません」と出ます。保存したあとの表示は「差はありません」です。開く、保存、別名保存の途中は押せません。

## 表示を動かす

### スクロール

チャートをドラッグすると、縦横にスクロールします。⌘またはCtrlを押しながらの矢印キーも、チャートのスクロールです。上で縦に戻り、下で進みます。左は過去へ、右は未来へです。上下は1行分で、左右も同じ画面上の距離です。押しているあいだは連続して動きます。止まるのは端です。検索欄や選択欄、ボタンにフォーカスがあっても動きます。矢印キーだけでは動きません。ダイアログが開いているあいだも動きません。

ホイールの縦の量は上下、横の量は左右です。左の名前の一覧の上でも、チャートの上でも同じです。タッチパッドでは、二本指を横へ滑らせるだけでも左右に動きます。斜めに滑らせたときは、縦と横が一緒に動きます。Shiftを押しながらのホイールは横です。左の一覧の上でも同じです。日付の行とマイルストンの帯の上では、ホイールの縦の量も横の量も左右に動きます。タッチパッドやドライバが横のイベントを出さないときは、チャートの空白をドラッグするか、Shiftを押しながらホイールを回してください。

縦スクロールで日付の行とマイルストンの下に残るのは、展開しているカテゴリとグループです。次の見出しが来ると入れ替わります。残らないのは、折りたたんだ行です。行が画面に収まるときも残りません。

### 拡大と表示単位

Ctrlまたは⌘を押しながらホイールを回すと、マウスの位置を基準に拡大・縮小します。左の一覧の上では、チャートの左端の日付を保って拡大・縮小します。ツールバーの「日」「週」「月」は、決まった大きさに切り替えます。「今日」は、今日の日付が見える位置へ横だけ動かします。「全体」を押すと、スケジュール全体の期間が画面の幅に収まる大きさになります。

### 折りたたみと一覧の幅

左の三角で、カテゴリやグループを畳めます。畳んでも残るのは、その行のバーです。タスクが無いグループとカテゴリには親バーは出ず、名前だけが見えます。左の名前が途中で切れているときは、その名前にマウスを乗せると全文が出ます。名前をドラッグしても動きません。タスク行は、左端の握りをドラッグして順を変えたり、別のグループへ移せます。握りをクリックしてもタスクは選ばれず、詳細パネルも開きません。右クリックでも選択やメニューは出ません。絞り込みや系統で兄弟が隠れているあいだは動かせません。グループ行は、左端の握りをドラッグして順を変えたり、別のカテゴリへ移せます。絞り込みや系統で同じカテゴリのグループが行に出ていないあいだは動かせません。カテゴリ行は、左端の握りをドラッグして順を変えられます。絞り込みや系統でカテゴリが行に出ていないあいだは動かせません。タスクの並べ替えでは、ドラッグ中に半透明のタスク行がポインタに付いて動きます。グループとカテゴリの並べ替えでは、見えている配下の行も含めた半透明の塊が付いて動きます。畳んでいるときは見出しの1行だけです。カテゴリ行とグループ行を右クリックすると、追加と、消せるときだけ削除が選べます。

左の一覧とチャートの境界を横にドラッグすると、一覧の幅を変えられます。ダブルクリックで戻るのは、元の幅です。境界にフォーカスがあるとき、左右キーでも幅が変わります。⌘またはCtrlを押しているときは幅を変えず、チャートが横に動きます。ウィンドウを狭めたときに縮むのは表示だけです。広げると戻ります。

## 絞り込む

画面上部の検索欄と「絞り込み」パネルの条件は、組み合わせて使えます。「帯の線」では、マイルストン帯に出すグループごとの線の表示を切り替えます。左のマイルストングループ名の行を右クリックしても切り替えられます。タスク一覧の「マイルストン」絞り込みとは別です。検索欄の左で「名前」か「ノート」を選びます。条件が効いているときは、その下に外せる札が出ます。「すべて解除」は絞り込みだけを戻し、系統は残ります。残るのは、すべての条件を満たすタスクだけです。残ったタスクが無いグループは、行ごと隠れます。

「前後」と「マイルストン」の絞り込みが使うのは、タスクが持つ次の情報です。タスクには、先に済ませておくタスクを登録できます。登録した相手の呼び方は、そのタスクの先行です。逆向きに見た相手を後続と呼びます。設定場所は詳細パネルの「先行タスク」と「後続タスク」です。タスクごとに、関係するマイルストンを1つ結び付けられます。選び方は詳細パネルの「対応マイルストン」です。

| 欄 | 使い方 |
| --- | --- |
| タスク名で検索 | 名前にその文字を含むタスク |
| ノートで検索 | ノートにその文字を含むタスク。ノートが無いタスクは残らない |
| 担当者 | 「割り当てなし」は、担当者のいないタスクと、担当者のIDがメンバーに見つからないタスクの両方 |
| ステータス | 「完了以外」は、完了していないタスク |
| 確度 | 「未確定」は日付が未合意のタスク。「確定」は合意済みのタスク。着手や進捗とは別 |
| 期限 | 「期限超過」は、今日より前に終わる未完了のタスク |
| 前後 | 「前後: 破綻のみ」は、後続が先行の終了より前に始まっている組 |
| マイルストン | 「なし」は、対応マイルストンが無いタスク。名前を選ぶと、そのマイルストンに結び付いたタスクだけ |
| タグ | そのファイルに出てくるタグをチェックで選ぶ。一つもオンにしていないときはタグでは絞らない。一つ以上オンのときは、そのどれかを付けたタスクだけ。選んだタグは札に出し、札を押すとそのタグだけ外れる |

タスクを選んで「系統」を押すと、そのタスクの前と後につながるタスクだけが残ります。ボタンに出るのは、起点にしたタスクの名前です。もう一度押すと解除します。絞り込みを変えると外れるのは、選んでいたタスクの選択です。

## 編集する

### 選択と移動

タスクを選ぶのは、右のバーまたは左の名前をクリックしたときです。右クリックでも選べます。↑↓で見えているタスクの前後へ移せます。

移動するには、バーの本体を横にドラッグします。⌘またはCtrlを押したドラッグでも同じです。少し動かすまでは選択だけが変わり、8pxを超えてから移動が始まります。ドラッグ中は開始日と終了日が`4/3`の形で出て、離すと消えます。日付が重ならない相手は、棒と、もう一方の日付です。確定するのは、離したときです。Escapeを押すと、離す前の日付に戻ります。空いた所、スペースキー、中ボタンのドラッグはスクロールのままで、日付は出ません。

期間を変えるには、バーの左右の端をドラッグします。選んでいなくても変えられます。端とその周りをクリックしても、タスクは選ばれず、詳細パネルは開きません。右クリックのメニューも出ません。1日より短くはできません。ドラッグ中に出る日付は、移動のときと同じく開始日と終了日です。確定するのは離したときです。Escapeを押すと、離す前の形に戻り、履歴には積まれません。

そのタスクが端になっている前後の線は、離す前の日付で色が変わります。後続の開始が先行の終了より前になると、赤く太くなります。同じ日なら赤くなりません。離すまで変わらないのは、他の線と、見えている行です。終了日を非稼働日にしても「休」は出ず、バーの長さは暦日のままです。

### 詳細パネルと線

タスクを選ぶと、チャートの右に詳細パネルが出ます。項目を変えると、その都度スケジュールに反映されます。バーの本体をダブルクリックするか、選択中にEnterを押すと、パネルの名前欄にフォーカスが移ります。端の当たりでは移りません。変えられる項目は、名前・ノート・タグ・日付・担当・ステータス・進捗・確度・対応マイルストン・先行・後続です。タグは札で外し、入力して Enter で足します。Alt+←→で開始日と終了日を、Shift+Alt+←→で終了日だけを1日ずらせます。

チャート上で線を足すには、タスクを選んで「線を引く」を押すか、⌘またはCtrl+Lを押します。Lだけでは始まりません。ボタンに出るのは起点の名前です。次にクリックしたタスクが後続になります。モードは残るので、続けて足せます。終わらせ方は、起点の再クリック・Esc・「線を引く」・⌘またはCtrl+Lです。すでに結ばれているときと、循環するときは足しません。失敗の理由は、チャート上端の帯に出ます。見えていないタスクへは引けません。詳細パネルの先行と後続も、今までどおり使えます。

線を外すには、線にカーソルを合わせてDeleteまたはBackspaceを押すか、右クリックの「線を外す」を選びます。確認は出ません。消えるのはその1本だけで、タスクは残ります。バーや、ひし形と名前の上では、今までどおりタスクの削除確認です。

### 右クリックと複製

タスクのバー、または左のタスク行を右クリックすると、メニューが出ます。項目は「編集」・「複製」、確度、ノート、系統、削除のあいだに区切りがあります。削除は赤い文字です。Enter、ノートの⌘NまたはCtrl+N、Deleteは項目の右に出ます。確度を切り替えても日付は動きません。線を引いているあいだは、このメニューは出ません。

「複製」では、元の内容を写したダイアログが開きます。写す項目はタスク名・ノート・日付・担当・ステータス・進捗・確度・対応マイルストン・先行です。後続は空です。名前を直して「追加」すると、同じグループの直後に足されます。同じ名前のままでも足せます。キャンセルとEscapeでは増えません。

マイルストンのひし形、またはその右の名前を右クリックすると、メニューが出ます。項目は「編集」と、今の確度と逆の「確定にする」または「未確定にする」と、「削除」です。確度を切り替えても日付は動きません。右クリックしても、タスクの選択は変わりません。

左のマイルストングループ名の行を右クリックすると、「非表示」と、帯に出ている別のグループ行があるときだけ「この行だけ表示」が出ます。どちらも「帯の線」のオンオフと同じです。右クリックしても、タスクの選択は変わりません。線を引いているあいだは、このメニューは出ません。

先行と後続の候補は、一度に50件まで出ます。多いときは、名前で検索して絞ります。

### ノートと名前

ノートを開く入口は、左のノートアイコン・右クリックの「ノート」・選択中の⌘またはCtrl+Nです。Nだけでは開きません。アイコンの色で、ノートの有無が分かります。空白だけにして保存したときに消えるのは、ノートです。

マイルストンの日付は、ひし形、またはその右の名前を横にドラッグして変えます。確度もグループも変わりません。名前・日付・確度を変える操作は、ひし形か名前のダブルクリックか、右クリックの「編集」です。マイルストングループが2件以上あるときは、編集でグループも選べます。帯の線がオフのグループや、中身が空のグループも候補に出ます。別のグループへ移したあと、移した先の帯の線がオフだったときは、そのグループだけオンに戻ります。取り消しでは線の表示は戻りません。名前が空白だけなら、元の名前のまま残ります。

カテゴリとグループの名前は、左の行をダブルクリックするか、右クリックの「名前を変更」で変えます。空白だけのときの結果は、元の名前のままです。すでに使っている名前には変えられません。折りたたんだままの行は、名前を変えても折りたたんだままです。

### 追加と削除

「追加」では、既存のカテゴリとグループを選び、そのグループの末尾にタスクを足します。終了日に指定した日も期間に含まれます。足したタスクの確度は未確定です。確度を「確定」で絞っているときだけ、その絞り込みは「すべて」に戻ります。

「マイルストン追加」で指定するのは、名前・日付・確度です。マイルストングループが2件以上あるときは、グループも選べます。マイルストンが無くても押せます。ツールバーから開いたときの名前は空です。日付は今日で、確度は未確定です。グループの初期値は、並びの先頭のグループです。先頭のグループに帯の行が無いときは、見えている帯の最上段とは別になります。日付ヘッダー・帯の空き・チャートの空きを右クリックして「マイルストンを追加」を選ぶと、同じダイアログが開きます。そのときの日付の初期値は、指した位置の日です。帯の空きから開いたときのグループの初期値は、指した縦位置のグループです。どのグループの帯にも入らない位置なら、並びの先頭のグループです。日付ヘッダーとチャートの空きから開いたときのグループの初期値も、並びの先頭のグループです。名前と確度の初期値は、ツールバーから開いたときと同じです。帯の線がオフのグループを選んで足しても、帯の線は変わりません。ひし形は、線をオンにするまで帯には出ません。右クリックでは、タスクの選択は変わりません。線を引いているあいだは、この項目は出ません。ひし形が出る位置は、指定した日付です。マイルストングループが1件のときは、先頭のグループに入ります。グループが無いときは、「マイルストン」というグループができます。未確定は斜線で、確定は塗りつぶしです。名前が空白だけ、または日付が空のときは足しません。ダイアログは開いたままです。同じ名前と日付でも足せます。キャンセルとEscapeでも足しません。

「削除」は、タスクを選んでから押します。DeleteまたはBackspaceでも同じ確認が開きます。消えるのは、確認のあとです。消したタスクとの前後関係は外れます。その前後にあったタスク同士を自動でつなぎ直すことはしません。ツールバーの「削除」とDeleteでは、マイルストンは消えません。

ひし形、またはその右の名前の右クリックの「削除」では、確認のあとにマイルストンが消えます。外れるのは、そのマイルストンを指していたタスクの対応だけです。日付は変わりません。絞り込んでいたマイルストンを消すと、マイルストンの絞り込みは「すべて」に戻ります。残るのは選択と系統です。取り消しても、絞り込みは「すべて」のままになります。

### 取り消しと、入力中のキー

取り消しのキーは⌘またはCtrl+Zです。やり直しは⌘またはCtrl+Shift+Zか、Ctrl+Yで行います。戻せるのは確定した編集だけで、最大100件です。絞り込みやスクロールは戻りません。

検索欄やダイアログへ文字を入力しているあいだ、取り消し・やり直し・Enterでの名前欄への移動・Deleteでの削除・線を引く・ノートを開くには使われません。詳細パネルの欄にフォーカスがあるときも、↑↓での選択移動とAlt+矢印での日付変更はその欄の操作のままです。⌘またはCtrl+S・⌘またはCtrl+Shift+S・⌘またはCtrl+O・⌘またはCtrl+Fは、検索欄にフォーカスがあっても効きます。⌘またはCtrlと矢印も、検索欄・選択欄・ボタンにフォーカスがあってもチャートをスクロールします。矢印キーだけのときの動作は、その欄の操作のままです。ダイアログが開いているあいだは、これらも効きません。⌘またはCtrl+Nは、ノートを開くときも開かないときも、ブラウザの新しいウィンドウにはなりません。開かない条件は、ダイアログ・選択が無いとき・線を引くモード・検索欄・選択欄です。タスクを選んでいるときは、ボタンにフォーカスがあっても開きます。

## 書き出す

残したい行だけになるように、絞り込み・折りたたみ・系統を使います。☰の「書き出し」で選ぶ形式はHTMLかSVGです。「書き出す」を押して保存します。

書き出しに入るのは、絞り込みや折りたたみで隠していない行と、その期間に関係するマイルストンです。画面の外にスクロールしている行も入ります。絞り込みで隠したタスクは入りません。日・週・月の表示単位は、画面と同じです。

行が10,000を超えるとき、または図が横200,000pxか縦50,000pxを超えるときは、保存せずに理由を表示します。絞り込みや折りたたみで範囲を減らしてください。

## 設定

デスクトップ版の☰の「設定」には、表示、メンバー、稼働日、更新、JSON作成スキルを置くの5つがあります。ブラウザ版には「更新」はありません。

「表示」では、文字と行とボタンの大きさと配色を変えます。開いているウィンドウでは、メンバー、カレンダー、文字の大きさ、配色、一覧の幅、行の密度、イナズマ線、一覧の列は同じです。配色はライトとダークと、システムに合わせる設定です。「自動」か、50%から200%を選びます。一段変えるキーは、Macでは⌘+と⌘−、それ以外ではCtrl++とCtrl+-です。検索欄やダイアログが開いていても変わります。チャートのズームはCtrlまたは⌘とホイールで、表示サイズとは別の設定です。同じ欄で、左一覧に開始・終了・日数・進捗を出せます。開始と終了は「09/19」のような月と日、日数は「12日」、進捗は「30%」です。開始、終了、日数、進捗、超過、担当は、行をまたいで同じ位置に揃います。超過が無い行も、その幅は空きます。担当が長いときは省略され、マウスを乗せると全文が出ます。初期はどれも出しません。

「メンバー」では、メンバーJSONを取り込みます。取り込んだ1件の呼び方は「カタログ」です。使うカタログを1つ選ぶと、タスクの担当者IDが名前で表示されます。メンバーを書く先は、スケジュールのファイルではありません。

「稼働日」では、休日と振替出勤を書いたJSONを1件取り込みます。未設定のときは土日を塗ります。変わらないのは、タスクの日付の計算です。

デスクトップ版には「更新」があります。既定はオフです。「起動時に更新を確認する」をオンにすると、次回の起動から [GitHub Releases](https://github.com/shkobayashi/schedule-viewer/releases) の新しい版を確認し、あれば入れ直します。オンにした直後は確認しません。自動更新で入れ直したあとの起動では、前面のウィンドウにその版の変更内容が一度だけ出ます。閉じたあとから、次の起動時の更新確認が始まります。手で入れたときは出ません。閉じた版は次の起動では出ません。各 Release のページにも、同じ版の変更が載ります。Ubuntu では入れ直しに管理者の確認が出ます。Windows では、更新の途中で SmartScreen の確認が出ることがあります。自動更新を含む版を一度手で入れたあとから、この機能の対象になります。

同じファイル名のカタログや、すでにあるカレンダーを取り込むときは、上書きしてよいかを聞きます。

「JSON作成スキルを置く」では、write-schedule、write-members、write-calendar の3つをまとめて置けます。Cursor と Claude Code のどちらへ置くか、ユーザー全体か指定したフォルダかを選びます。自分の作業ならユーザー全体、チームで同じ手順をリポジトリに残すなら指定したフォルダを使います。置いたパスだけを示し、git には入れません。同名フォルダがあるときは上書きを確認します。「外す」で、同じ選び方の場所から3つだけ削除できます。デスクトップ版だけ使えます。ブラウザ版では同じ欄に、デスクトップ版で置く旨だけ出ます。`.cursor` と `.claude` と `skills` がシンボリックリンクのときは置けません。外すときも、リンクの先は消しません。

## ほかのプログラムがファイルを書き換えたとき

デスクトップ版が定期的に確かめるのは、開いているファイルが書き換えられていないかです。

未保存の編集がなく、詳細パネルにも入力の途中が無いとき、内容に問題が無ければ画面へ反映します。反映した直後は、画面の隅に「ファイルを反映しました」と数秒出ます。

未保存の編集があるときの選択肢は、「読み直す」か「画面の編集を残す」かです。残したあとは、状態バーの「ファイルに更新あり — 読み直す」から同じ確認に戻れます。

「保存」を押したときに、開いたあとでファイルが書き換えられていれば、次から選びます。選択肢は「上書き保存」・「別名保存」・「取り消し」です。

## 閉じたあとに、また開くとき

デスクトップ版では、閉じる前に開いていたウィンドウを覚え、次回起動時にそれぞれを戻します。同じファイルを複数のウィンドウで開いていたときは、閉じた時点で前面にあったウィンドウの未保存だけを控えに残します。

開いていたスケジュールJSONも、ウィンドウごとに覚えています。次に起動すると、そのファイルを開き直します。保存して閉じたときも、未保存のまま閉じたときも、同じです。戻さないのは、絞り込み・折りたたみ・ズーム・スクロール・系統・選択です。

開き終わるまでは、画面上の日付やタスクは変えられません。開き終わったあとは変えられます。開き終わる前に別のプログラムがファイルを書き換えていても、開いたあとでその内容を読みます。ファイルへの書き込みは、起動中も止めません。

未保存のまま閉じたときは、保存していない編集もアプリの中に残します。開いているファイルそのものは書き換えません。次に起動したとき、ファイルが閉じたときのままなら、閉じる前の編集中の状態に戻ります。そのあいだにファイルが書き換えられていたときの選択肢は、「ファイルを開く」か「未保存の編集を戻す」かです。

前回のファイルが無く、未保存の編集も無いときは、そのことを知らせてサンプルを表示します。未保存の編集があるときに画面へ戻すのは、その内容です。ファイルが無いことも知らせます。「ファイルを開く」では、覚えたパスを直接開かず、フォルダから選び直す操作です。作業中にファイルが読めなくなったときも、続けて読めなくなってから、同じ選び直しになります。キャンセルしたときに残るのは、画面の内容です。

サンプルを編集したまま閉じるときは、戻す先のファイルが無いので次回はサンプルのままです。破棄して閉じてよいかを確認します。

## LLMでスケジュール、メンバー、カレンダーを作る

スケジュールJSON・メンバーJSON・カレンダーJSONは、このリポジトリにあるスキルを使ってLLMに作らせます。スキルは、LLMのエージェントに渡す手順書と検証スクリプトをまとめたフォルダです。デスクトップ版の設定「JSON作成スキルを置く」から、Cursor または Claude Code のスキルフォルダへ置けます。手でコピーして使うこともできます。

スケジュールJSONの作り方は`.cursor/skills/write-schedule`です。担当者を付けるときは、メンバーJSONにあるIDだけを使います。IDの一覧を渡していないときの動作は、JSONを作らず、一覧が足りないと伝えることです。

メンバーJSONは`.cursor/skills/write-members`で作ります。書くのは渡したIDと表示名だけで、IDは名前から推測しません。

カレンダーJSONは`.cursor/skills/write-calendar`で作ります。書くのは渡した日付だけで、祝日は推測しません。

どのスキルも、書いたあとに同梱の検証スクリプトで中身を確かめます。形式の詳細の場所は[データ仕様](data-format.md)です。画面で日付やタスクを直したあとは、「差分を表示」のテキストを渡します。スケジュール全文を二つ渡さなくても、伝わるのは変更だけです。

## 困ったとき

### ファイルが開けない

確認するのは、ダイアログに出るエラーの内容です。問題の場所は、カテゴリ・グループ・タスクの名前で示されます。開ける版はschemaVersion 3〜7です。3は、確度が無いタスクを確定として読みます。4が付けるのは、カテゴリとグループのIDです。5はマイルストンに確度を足します。6はマイルストン帯のグループ（`milestoneGroups` と `groupId`）です。7はタスクの `tags` です。古いファイルを開いただけでは未保存になりません。保存すると7になります。担当者を名前で書いたschemaVersion 2は開けません。

### 担当が「メンバー不明」になる

設定の「メンバー」で、そのIDを含むカタログを選んでください。カタログを選んでいないときも、IDがある担当はメンバー不明になります。

### 「メンバー設定エラー」「カレンダー設定エラー」が出る

見出しのその表示にマウスを乗せて、理由を確認します。カレンダーのエラーが直るまで塗るのは、土日だけです。

### WindowsでSmartScreenが出る

GitHub Releases の Windows インストーラは自己署名です。同じ Release の `schedule-viewer-codesign.cer` を、管理者権限で「信頼されたルート証明機関」と「信頼された発行元」へ一度入れた PC では、発行元が `schedule-viewer` と表示されます。証明書を入れていない PC では SmartScreen の確認が出ます。入手元が GitHub Releases であることを確認してから進めてください。入れ方は [開発ガイドの「Release 後に証明書を入れる」](development.md#release-後に証明書を入れる) にあります。

### 書き出せない

超えているのは、行数か、図の幅か高さです。絞り込みや折りたたみで行を減らしてください。

### ブラウザ版とデスクトップ版の違い

ブラウザ版では、「開く」がファイル選択で、「保存」と「書き出し」がダウンロードになります。「新しいウィンドウで開く」は出ません。別のプログラムがファイルを書き換えても、画面には反映しません。閉じたあとに前回のファイルや未保存の編集を戻すこともありません。メンバーと稼働日の設定は、そのブラウザの中に残ります。ファイルの上限はデスクトップ版と同じです。スケジュールは10MBで、メンバーと稼働日は1件2MBです。保存領域に書けないときは、その旨が出ます。
